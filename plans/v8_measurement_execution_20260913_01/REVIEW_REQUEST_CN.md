## 复现范围

小型包中的 `portable_replay_01/` 可在 Python 3.11+、无模型权重和 API key 的环境运行
`python3 replay.py`。它禁用 Python 网络调用，重放两个原始 216 机会的真实程序 journal，
结果应精确匹配原独立评分。搬迁到不同路径的实际复验回执位于 `portable_relocation_01/`。

这不代表上游所有大型原始数据、全部模型 token 或历史发布 ZIP 已在另一台机器完整重建。
包中保留相关 GPU 批次的冻结 Python 源码，也提供后续开发中的当前源码；两者有意分别存放。
复核原 GPU 结果必须使用各自冻结实现，不能将当前新增 D/X09 代码替换进去。
完整核心测试仍可能引用小型包以外的历史原生 fixture；免权重、免外部资料的直接执行入口
是上述 portable journal 子集，而不是声称整个历史仓库可以由此 ZIP 完整重建。
若本次复查没有运行某项检查，请明确说明阅读了哪些文件、实际执行了哪些代码。
合成反例可以帮助检查边界，但应与真实引擎入口测试、实际模型错误分别列出。
