## 已完成的实质工作

1. **年度来源从样例推进到完整日历。** 3 个地区、2023—2024 年共 72 个月完成原生 TAF/METAR 构建。58,221 个唯一原文请求中复用 5,673 个已验证缓存，补齐 52,548 个原文；9 次超时及其一次性重试保留。目录、字节、解析和标签分别核验，不把下载成功当作每条语义都成功。
2. **年度预测器冻结并用于真实模型比较。** 使用 2023 拟合、2024 年 1—11 月校准，先冻结 bank 再进入 2025 开发会话。旧 2024 年 12 月未进入本次拟合/校准。动态来源角色交叉检查通过；这些资料不冒称未见确认集。
3. **C2 获取到概率的实际消费链运行。** 六父状态重建、六次原策略续跑一致，24 个正式处理分支完成。36 个配对均出现特征及实际生效概率变化；六父同日且已结算正例均为零，目前支持工程诊断和负例误差分析。
4. **正式模型实验及强对照完成。** DeepSeek-V4-Flash 作为查询选择器，共 12 个已暴露日会话、9 条件、108 个方法运行、288 个真实 API 请求。概率由冻结程序输出。24 个正式评分组通过，展示统计与正式评分的 108 个方法会话逐组核对一致。
5. **实现与保全验收。** 628 个去重测试无失败、无跳过。原 188 项保护清单中 181 项未变，7 个当前实现文件为已登记修改；独立源码快照无差异。原始失败、STOP、模型回复和旧科学结果保留。

## 模型结果应如何解读

此次目标为历史回放中的未来站报能见度低于 5,000 米。每方法注册 864 个机会，其中 861 个可结算、3 个缺失。**16 个正例全部来自 `chicago__2025-12-01__5000`；它们不是 16 个独立天气过程。** 四个全球周块也不自动建立过程独立性。

F_COMMON 与其他程序预测条件采用不同 bank，不能将其差异全部归于获取策略。FOLLOW 的概率也含研究映射，不等于专业机构直接给出的原生概率。

模型相对 F_BASE_ONLY 的平均改善仅为 **0.0000319736**，全部来自负例；正例贡献为 0。考虑 3 个缺失结果的逐预测值敏感性界为 **[-0.0000576464, 0.0000339670]**，跨过零；这是缺失敏感性界，不是置信区间。模型没有超过同一 values bank 下的强覆盖率或批量共享规则。

不能把这个结果直接解释成模型推理能力不足：288 次回复中仅 71 次满足原契约，192 次结构错误、25 次 JSON 外文字或不可直接解析内容。合法回复中 58 次不查询、13 次按原顺序选全部三个候选，未观察到严格子集或重排。实际取得 38 个来源回执，其中一个订正时序无法证明；合法选择与正确事实取得仍分开。

所有请求均 HTTP 200、模型 ID 一致、正常 stop 结束；供应方记录 726,113 输入 token、12,521 输出 token，共 738,634 个正式请求 token。两个合成兼容性请求另计。供应方实际账单未知，不能将费用记为零。

第二个兼容性名额采用 strict JSON schema，在相同合成题上通过结构与选择检查。它说明该模式值得实施，**尚未证明完整天气接口可用**，也没有替换或重跑本轮回复。

## 当前 novelty 的证据边界

- C1 已有共享预算/权限的真实 2×2 与强批量对照，但这次合法模型行为没有展示精细主动分配，正例过程覆盖也不足。
- C2 已有相同父状态的真实有限分支以及字段、特征、概率、损失链；还需要不同原生证据状态、真实 TAF 干预和多个独立过程的重复证据。
- C3 的本轮新增交付是 H15 年度来源与开发实验闭环；其余灾种仍按各自 A0—A5、E/F/D/MM 门槛推进。不能将候选目录数量写成全部可执行任务数量。

本轮有实质数据与工程进展，同时也给出了负面的模型效果结论。增加模型数量或放大计算规模不能替代这些未满足的科学门槛。

## 接下来按此顺序推进

1. **有界修复查询接口。** 在新版本加入 strict schema 和清晰的程序预测契约，先通过离线异常测试，再用新的小额真实天气兼容性范围验证。保留旧自由输出轨道，禁止改写字段后回填为合法查询。具体见 `SELECTOR_INTERFACE_V2_PROPOSAL_CN.md`。
2. **检查取证信息究竟如何产生价值。** 固定年度 bank 和已暴露开发日历，分别检查实际取得、合法支持、特征变化、概率变化及正负例贡献；核查拟合 cutoff−600 秒与实际预测时点的差异。若需要新 bank，冻结新版本，旧结果仍保留。
3. **让 C2 和正例支持覆盖多个过程。** 依据公开来源状态预先选择缺报、删失、冲突、订正与 TAF 条件窗口，再冻结父会话和有限取证计划。未来标签与损失不能用于挑选最有利父样本；正例不足如实记录。
4. **固定两条确认协议，再开放未读历史。** 模型增量与 C2 诊断重现分别注册；共同日历首次打开前同时冻结，或采用隔离日历。无需等待真实未来。当前 Bay 确认资料仍关闭。
5. **扩展第二条合格灾种链和原生视觉。** 优先处理温度 F-only 的资格，再在降水/水文中完成同目标主动链；图片样例可读不等于 VLM 评测完成，16 类完整发布仍按出口门槛推进。
