# DisasterTrace ActiveWarning 最小闭环实施记录

开始日期：2026-09-12。用户要求使用规划中已有的数据源实现并测试最小闭环，暂不接入 GEE。

## 本轮要回答的问题

从真实历史预报出发，固定一个未来绝对时刻，限制查询预算与交付时间，保存模型每轮预测，最后用隔离的事后结果自动结算。比较取得新版官方预报的收益，以及在最新版基础上增加的收益；保留无收益和负收益。

## 执行顺序

1. 冻结数据与协议：先复用 NHC 公告和 HURDAT2 的开发组，再配对已有 HEFS SCOC1 集合预报与 USGS 同站流量。只根据输入覆盖选择任务，结果缺测保留为未结算。
2. 增量实现 `active_warning_v1`：固定目标、来源/版本、独立逻辑时钟、查询完成与读取、有限预算、不可回写提交、截止评分、私有结果结算与可复算日志。
3. 运行固定流程和机制对照：持久性、初始/最新专业预报、固定查询、来源/时间感知、预算允许的全读；另列重复、旧版重送和迟到资料的受控干预。
4. 冻结小规模本地模型实验，在最多四张 H100 上执行，记录实际提示、响应、token、失败与运行时间；不复用旧实验的启动记录，不使用付费 API 或 LLM judge。
5. 给出实际结果、负结果、数据缺口与 novelty 可行性判断，明确哪些研究主张尚未得到支持。

## 数据和解释边界

- NHC：固定未来风暴最大持续风速，主要评分 MAE；HURDAT2 为同机构事后分析参考，不称为独立原始观测。64 kt 阈值仅对应风暴强度，不对应某地点风风险。点预报的 0/1 越阈不能包装为经过校准的强概率基线。
- HEFS / USGS：先核对 SCOC1 与 USGS-11477000、QINE / 00060、CFS / ft^3/s、瞬时支持、成员和质量。该站当前官方流量警戒阈值缺失，不用水位阈值代替；首轮连续流量预测可成立，洪水预警二元主任务须保留准入缺口。
- 现有历史公开可用时间未知，保留 null。本轮使用明确标注的受控历史回放，不称为已经完成前瞻在线预警验证。
- 不为凑来源数量把 CAMS、ERA5-Land 或卫星样例拼入不相关事件；只有目标、时间和结果一致的来源进入同一任务。
- 同一风暴的多个目标及同一流域的多个时刻不计为独立事件。全部为开发试点，不声称未见测试泛化或统计显著性。

## 预先确定的失败判据

如果取得最新版官方预报已经解决全部选择问题、全读足够廉价、附加观测没有增量，报告这个限制，不通过人为调预算保证主动策略胜出。重复/迟到干预可以验证环境与失败机制，但不能单独证明论文相对已有工作具有足够新颖性。

模型输出无效、未读引用、超预算、迟到和结果缺测分别记账，不删除困难样例。所有模型可见输入排除私有结果与私有最优证书。
