# DisasterTrace ActiveWarning：真实数据最小闭环与模型试点结果

日期：2026-09-12。用户要求使用已有规划数据，暂不使用 GEE，实际实现和测试后续方案及 novelty 的可行性。

**最小闭环已经完成；主动获取能够提高预警价值这一核心研究假设，尚未被本轮结果支持。** 本轮得到的是可运行、可复算的未来预测试验平台，以及具体的负结果和扩展条件。现有证据不足以宣称论文的完整创新主张已经验证成功。

## 1. 完成了什么

从真实产品构建 84 个固定未来目标，运行 7,056 条程序基线轨迹。随后在 ACP 上进行两轮完整 Qwen3-8B 模型试点，每轮 200 条轨迹、560 次实际回复。每轮使用四个单 H100 任务，全部八个任务最终均为 SUCCEEDED，任一轮最多并行四卡。

第一轮发现长目标编号复制错误；第二轮仅将公开编号改为短编号，保持数值、时间、结果标签、模型、提示文本、策略、预算和完整矩阵不变。两轮是开发阶段的协议迭代，不是新增独立天气事件，也不合并成两次确认性重复试验。

| 产物/验证 | 实际结果 |
| --- | --- |
| 数据 | 4 个气旋过程的 80 个目标；同一河流站点连续片段的 4 个目标 |
| 结果覆盖 | 74 个气旋事后参考 + 4 个水文暂定观测；6 个气旋目标未结算 |
| 程序实验 | 84 目标 × 4 场景 × 3 预算 × 7 方法 = 7,056 轨迹 |
| 每轮模型实验 | 20 目标 × 2 场景 × 5 策略 = 200 轨迹、400 次预测和 160 次获取决策 |
| 首轮模型协议 | 560 回复均正常结束；17/400 次预测抄错目标编号，383 次合法提交；失败保留 |
| 短编号复测 | 560 回复均正常结束；400/400 次预测合法、无重试、无缺失回复 |
| 自动测试 | 59 项既有 active_forecast 测试 + 26 项新环境测试 + 12 项捕获审计测试，共 97 项通过 |
| 数据复建 | episodes、outcomes、pilot IDs 和来源绑定四个确定性文件逐字节一致 |
| 模型复算 | 两轮全部请求/原始回复/token/环境轨迹在 CPU 端重建通过 |
| 独立数值复算 | 不导入项目评分器，用标准库重新计算全部程序和模型轨迹的点误差、专业参考、回退和组平均 |

没有调用付费模型 API，没有训练模型，没有人工逐题复核或 LLM judge。自动结算使用来源明确的数值参考，保留结果暂定和缺测状态。

## 2. 闭环如何工作

```mermaid
flowchart LR
    A[真实预报与此前观测] --> B[固定未来目标与时间合同]
    B --> C[有预算的资料查询]
    C --> D[完成后读取资料]
    D --> E[同一个 LLM 预测未来数值]
    E --> F[检查点提交与不可回写日志]
    F --> G[CPU 自动结算与复算]
    H[隔离的事后参考或后续观测] --> G
```

实现位于 [active_warning_v1](../../disastertrace-starter/src/disastertrace/active_warning_v1/)。环境区分请求、完成、读取与提交，使用请求时刻的版本快照，限制查询数量和并发，拒绝未来观测、未读引用、错误目标、无效数值及超预算动作。

本轮是**受控历史回放**。原始数据真实，但历史公开可用时间尚未被证明；来源释放延迟和工具服务延迟是明示的实验条件。模型只在两个预置机会选择资料，不自主安排检查点或现实准备行动。这些区别详见 [数据与时间合同](DATA_CONTRACT_CN.md)。

## 3. 真正使用的数据

| 任务 | 输入 | 自动结算 | 可以确认 | 仍不支持 |
| --- | --- | --- | --- | --- |
| 气旋未来强度 | NHC 同目标多版本预报和当前强度 | HURDAT2 精确时刻风速 | 固定目标预测、专业基线、版本与重复信息诊断 | 独立传感器真值、当地风灾风险、自然监测发生率、真实在线表现 |
| 河流未来流量 | HEFS SCOC1 两轮 45 成员集合；USGS-11477000 此前流量 | 同站同单位同时间的 USGS 流量 | 跨来源站点配对、连续变量预测与结果结算 | 洪水越阈预警、极端洪峰表现、跨流域泛化 |

本轮新下载了 USGS 的 169 条连续观测，并逐成员读取已有 HEFS 集合值。四个水文目标的结果为 105、107、107、110 ft^3/s，属于短而平静的片段；官方流量警戒阈值缺失，不能用水位阈值替代。

GEE 按要求排除。CAMS、GloFAS、EFAS、ERA5-Land、IMERG、SMAP 等已有可下载/可解码证据，但尚未为本次目标形成完整一致的预测链，因此没有为了增加来源数量拼入本轮评分。16 类灾害的整体覆盖目标保留，本轮模型闭环只覆盖这两个任务族。

## 4. 预先固定的比较方法

| 策略 | 每条轨迹查询配额 | 模型的作用 |
| --- | ---: | --- |
| fixed_forecast | 2 | 固定每轮查官方预报；LLM 做预测 |
| fixed_observation | 2 | 固定每轮查近期观测；同一个 LLM 做预测 |
| active_raw | 2 | LLM 选择查询；同一个 LLM、相同预测提示和原始视图做预测 |
| active_canonical | 2 | 选择和预测前均整理已读版本与重复事实；LLM 后端相同 |
| all_read | 4 | 每轮并行读预报和观测；LLM 做预测，作为额外资源参考 |

active_raw 与两个固定策略用于同预算、同预测器的获取比较。active_canonical 同时改变获取输入和预测输入，测的是组合表示/状态处理效果，不能称为隔离了内部记忆的因果实验。all_read 的预算更高，不是预算 2 策略的等资源对手。

当前 canonical 实现适用于本轮每种事实的单一产品版本链。它按目标、变量、时刻等字段选当前版本，尚不是处理多个独立预报中心、同化依赖和不确定来源关系的通用融合器。接入多个预报中心前需要显式产品谱系键，不能直接合并同目标的独立产品。

## 5. 短编号复测的主要结果

下表使用相同 20 个开发目标，按组平均 MAE，越低越好。气旋有 4 个过程、16 个目标，其中 13 个可结算；水文只有 1 个连续过程、4 个可结算目标。未结算目标仍保留在总机会数中，不转成负例。

### 正常资料条件

| 方法 | 气旋 MAE，kt | 河流流量 MAE，ft^3/s |
| --- | ---: | ---: |
| 程序：初始专业预报 | 10.9375 | 17.2975 |
| 程序：最新专业预报 | 7.1875 | 15.1763 |
| 程序：近期观测持久性 | 23.5417 | **1.8750** |
| LLM：固定查预报 | 6.9792 | 15.3738 |
| LLM：固定查观测 | 9.5833 | 13.7450 |
| LLM：主动获取，原始视图 | 6.9792 | 15.3738 |
| LLM：主动获取，版本整理 | 7.1875 | 15.1763 |
| LLM：全读，预算 4 | 7.0313 | 15.3738 |

程序持久性与专业预报使用不同预测规则，二者对比不是“只改变获取策略”的因果实验。它揭示的是该片段中近期流量有可利用的预测价值，并提供应该超越的简单强基线。

可以直接得到三个结论：

1. **主动选择没有产生增量。** 第二轮 160 次获取决策全部选择 `forecast`。active_raw 与 fixed_forecast 的 40 对轨迹查询序列一致，80 对预测提示和原始回复也逐字一致。增加获取决策调用只增加了开销。
2. **简单强基线会改变对 LLM 的判断。** 在气旋中，读取新版专业预报相较初始预报的收益明显；在本轮平静水文片段中，近期观测持久性远好于 HEFS 均值和所有测试 LLM 策略。LLM 已经读到流量并不保证它有效使用流量。
3. **更多读取不保证更好。** 预算 4 全读未形成稳定优势。不能据此人为增加工具延迟或修改预算，让主动策略必然胜出。

LLM 气旋点分数比最新专业预报低约 0.21 kt，仅是本试点均值差，来自四个已暴露过程；没有置信区间或显著性证据，不能写成超越 NHC 的稳健预测能力。

### 旧版本重送条件

| LLM 策略 | 正常气旋 MAE | 旧版重送气旋 MAE | 改变的气旋检查点预测 |
| --- | ---: | ---: | ---: |
| 固定查预报 | 6.9792 | 7.3438 | 2/32 |
| 主动获取，原始视图 | 6.9792 | 7.3438 | 2/32 |
| 主动获取，版本整理 | 7.1875 | 7.1875 | 0/32 |
| 全读，预算 4 | 7.0313 | 7.2917 | 3/32 |

水文各策略在两条件间的点预测均未改变。版本整理后，20 对目标的全部 80 对模型提示及回复一致；这是可复现的输入规范化稳定性结果。正常条件下版本整理的气旋 MAE反而略高于原始视图，所以不能把“更稳定”直接写成“预测更准确”。

该诊断没有等长度控制，没有检验真正新增的影像证据，也没有分离所有外部状态/表示因素。它不是完整 LEAP 复现，更不是新颖性成立的充分证据。

## 6. 首轮失败怎样处理

首轮有 17 个目标编号复制错误，例如把 `aw-db0632e283a30efe` 写成多出字符的编号。评分器拒收这类回复，并按预定规则沿用已有提交或初始预报；没有依据答案数值进行宽松纠错。

这暴露了一个测量问题：不应让长不透明编号的复制困难主导天气任务。随后完整数据统一映射到短编号，映射保存在 [ALIAS_MAP.json](dataset_short_ids_v1/ALIAS_MAP.json)，完整再跑所有策略与条件。第二轮没有编号错误。

首轮结果完整保留在 [model_results_01](model_results_01/)，第二轮在 [model_results_02](model_results_02/)。更换提示中的编号也可能改变合法数值输出，因此两轮只能作为协议迭代分别报告，不能按题择优合并，也不能把第二轮叫作未见测试。

## 7. 对 novelty 的判断

本轮沿用 [2026-09-11 已保存的文献与代码核查](../v6_active_warning_review_20260911/RESEARCH_PLAN_CN.md)，没有声称重新完成全面文献检索。该核查已包括 SIREN、EarthVerse、AFABench、LEAP、动态交互评测和天气专业验证等近邻，不能把“灾害 Agent”“主动获取”或“去重”单独描述为首次提出。

| 原计划研究点 | 本轮能否测量 | 当前证据 | 判断 |
| --- | --- | --- | --- |
| 在固定专业预报基础上，限时取证是否有增量 | 能，已经有同模型同预算比较与专业基线 | 主动策略退化为固定查预报；水文简单基线更强 | 工程可行，核心正向收益假设未获支持 |
| 新内容、同源重复、版本与状态能否分开研究 | 部分能，程序有四场景，模型已做旧版重送 | 原始提示受旧版重送影响，规范化可保持稳定 | 有可复现实例；尚不够支撑通用来源依赖方法或多模态贡献 |
| 能否区分取证、处理、及时性与预测能力的失效 | 部分能，记录到达、读取、提交、强基线与失败 | 可识别编号复制失败及未利用观测的现象 | 尚未识别真实到达延迟、极端等级或跨事件失败边界 |
| 是否具有前瞻在线评测能力的实证 | 本轮没有 | 历史公开可用时间仍未知，结果在实验前已存在 | 需要单独前瞻影子队列 |
| 是否可宣称现实预警/经济收益 | 本轮没有 | 水文阈值缺失，概率基线未校准，行动时机未建模 | 暂不可主张 |

**建议继续研究，但调整近期目标：先证明真实数据中存在可重复的资料增量与选择需求。** 如果在新增合格事件中，固定轮询、近期观测或廉价全读始终足够好，应把结论写成主动系统的适用边界，而不是强行推出一种更复杂的策略。

## 8. 下一阶段的整体方向

### A. 先让水文成为合格的极端任务

优先扩到多个流域/站点，覆盖普通、近阈值、快速上涨、实际洪峰及缺测过程。固定监测窗口后保留所有机会，不依据某方法的预测误差选题。先做 3–5 个独立过程的链路检查，再依据事件覆盖和方差确定较大样本规模。

每个站点必须具备同变量预报、观测与阈值；有官方流量阈值的站点可进入对应预警任务。若使用历史分位数，阈值只在开发历史期定义，并明确称为统计极端流量，不称为官方警戒线。

### B. 用已有来源增加有意义的证据差异

将合适的降雨/湿润程度资料与具体流域、目标时窗、真实可用版本相连，先测试简单数值融合能否利用它们，再评估 LLM 选择。GloFAS/EFAS 可提供另一个预报来源，但需要站点/网格与空间支持核验，并保留不同产品谱系。

接着选择一条时间链较短的迁移任务：TAF + METAR 的未来低能见度，或 GFS/GEFS + 地面站的温度极端。选择依据是完整链路和独立事件覆盖；不以数据集数量作为创新强度指标。

### C. 分别加强模型协议和研究实验

保留短编号与后台内容绑定；后续引入多个预报中心时先扩展产品谱系键。让专业数值模型、持久性、简单偏差订正/融合承担强基线，再测试 Agent 的获取增量。概率基线需在单独开发资料上校准。

为机制实验增加真正的新观测、同信息不同表示、精确副本、等长度干扰和时间延迟，控制不住的因素明确称为诊断。模型时机策略需要独立扩展动作空间和准备时间合同，本轮的两个固定机会不能代替它。

### D. 单独建立前瞻影子队列

预先登记站点、目标、采集时次和截止；持续保存真实首次见到时间和每次产品版本，在结果发生前提交预测，之后按质量成熟规则结算。这里仍然不需要 GEE。HEFS 短滚动窗口使版本归档成为优先事项，未来结果成熟需要真实时间，无法靠 GPU 加速。

确认性评测在上述定义稳定后按新事件/流域/季节冻结。首版仍可聚焦少量合格任务族，16 类灾害的样例覆盖与正式主动预警主榜分别管理。
