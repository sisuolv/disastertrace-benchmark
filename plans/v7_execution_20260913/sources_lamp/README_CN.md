# W1A：LAMP/LAV 真实数据准入小样例

本目录执行 v7 计划的 LAMP 数据源验证。样例固定为 2024 年 1 月 1 日的 KSFO/KDEN/KAPA 历史预报、官方 2024 年 1 月 00:00/00:30Z 成员，以及执行当天可取得的 2026-09-13 00:30Z 原生产品。选样依据是明确日期、已有试验站点和目录中的第一个历史月，不依据任何模型收益筛选。

最终共记录 25 次请求、29,953,706 字节响应内容；19 次 HTTP 200、6 次 HTTP 206。其中一份目录列表触发 1MB 下载上限，另一次 IEM AFOS 请求没有找到历史产品，两者均保留。两份完整历史 gzip 成员通过 CRC，分别含 2,313 站、31 天的原生 bulletin；本轮实际解析 3 站的 2,604 条历史预报记录。

**最重要的时间核验：IEM `runtime=2024-01-01 00Z` 的 3 站 75 行，与官方原生 `00:30Z` 的 525 个字段完全一致。** 00:00Z 原生更新只提供前三小时的类别，而 00:30Z 原生标准产品提供 25 小时、更多气象变量。该结果证明必须在适配器中区分导出 runtime、原生 bulletin 时刻和可用时刻；本轮仍没有证明当年的首次公开可用时刻。

每个下载保留 URL、请求时间、状态、响应长度、SHA256、HTTP 日期以及有则保留的 Last-Modified/ETag。年度归档保存范围请求和 tar 成员头；成员完成后验证 gzip CRC。全部下载量和最终核验结果以 `REPORT.json` 为准。`raw/` 中保留了未成功得到科学数据的响应。

另已验证官方直接月/时刻 gzip URL 的 2KB 范围请求，例如 `lmp_lavtxt.202401.0030z.gz`，其前缀与年包中的同名成员一致。后续规模化获取可以优先固定月/时刻对象。本轮没有下载完整年度包，也不把成员 CRC 或部分范围 SHA256 表述为全年度归档校验。

## 必须保留的语义边界

1. **历史 LAV 的 `VIS` 是预测类别。** 它不是官方能见度概率，也不是物理观测真值。可以将“该版本产品写了什么”用作精确 E 任务；映射到未来观测概率必须通过独立训练/校准，并归入 R 轨。
2. **原生概率的阈值不能改名。** `VPVL`、`VPL`、`VPI`、`VPM` 分别对应 `<0.5 mile`、`<1 mile`、`<3 mile`、`<=5 mile`；1 mile 为 1609.344 米。它们不能直接替换已有 `<1000m`、`<5000m` 题目的同目标专业概率。
3. **15 分钟最小能见度不能用一条瞬时 METAR 代替。** 当前原生概率产品描述窗口中的最低能见度。匹配结果需要另行核对官方验证定义、原生观测采样与完整覆盖；本轮没有把这些窗口结算成 F 标签。
4. **保留原生分钟和窗口。** IEM 导出的整点 `runtime` 不直接等于原生 bulletin 的发布时间。官方 00:00Z 是短时类别更新，00:30Z 是标准小时产品；`REPORT.json` 中分别与 IEM 00Z 数值比较。所有历史可用时间仍需专门准入。
5. **当前可下载不等于历史时间链已通过。** HTTP Last-Modified 是本次服务器对象元数据，历史年包的 Last-Modified 不能代替当年产品首次发布时刻。下载时已经过去的窗口不算本轮在线预测。
6. **保留原生整数概率。** 文件里的互补百分比之和存在 99 和 100 两种情况；解析器不擅自归一化，也不将原生 99% 当作数值缺测码。完整概率行必须在范围内且累计阈值单调。

## 对后续计划的调整建议

- 先用官方历史原生 LAV 扩展 E 的版本、窗口、字段继承和产品读取实验；以月份/完整站群冻结，保留所有缺测和修订，不按模型表现选日期。
- 将 LAV 作为现有 TAF 对照的一个强研究基线候选。确认历史可用时间、结果配对和独立校准后，在相同目标与共同信息下比较。不能因为它是 NOAA 产品，就将经验映射误称为同目标原生专业概率。
- 原生 15 分钟概率另列 P 轨准入候选：保留官方阈值和窗口，先补观测参考与历史概率档案的证据。只有取得这些证据后才建 F 任务；当前 `<1000m/<5000m` 主轨不因此改题。
- BUFR 需官方 MDL 本地表与解码交叉检查；已成功解码的原生文本概率路线可以继续推进，不需要等待 BUFR 才承认数据源可读。
- LAMP 的共同专业预报应进入共同基线视图。将同一全站 bulletin 的物理文件缓存节省与主动补充证据的 C1 收益分开测量。

## 复现

在仓库根目录运行：

```bash
python -m unittest discover -s plans/v7_execution_20260913/sources_lamp -p 'test_*.py' -v
python plans/v7_execution_20260913/sources_lamp/validate.py
```

`validate.py` 离线重算原始文件校验、gzip/tar 成员验证、历史 JSON/CSV 交叉核对、原生 LAV 解析、原生概率解析和严格语义门槛，不调用模型或网络。

重跑 BUFR 兼容性探针使用现有独立科学库：

```bash
PYTHONPATH=/mnt/afs/260010168/.venvs/disastertrace-multihazard-libs-20260911 \
python plans/v7_execution_20260913/sources_lamp/bufr_probe.py
```

已保留 `BUFR_DECODER_RESULT.json` 和 stderr。该探针成功执行表示成功记录兼容性结果，不表示科学字段解包成功。

本轮完成真实下载和字段解码，不作模型收益、独立过程 C1/C2 效果或正式 A5 准入结论。后续是否可作为 P/R 基线，要由目标、可用时间、观测结果和校准合同共同决定。
