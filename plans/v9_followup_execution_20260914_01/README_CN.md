## 已经核验的工程部分

616 项相关测试通过，无失败、错误或跳过。生产 spool 绑定当前实现与配置；串行恢复累计多次等待和进程间隔；未知执行保留资源预留。受约束的托管工作流不等于任意 Python 代码隔离，也不等于外部服务的通用 exactly-once。

## 数据与区域基线

原有 Bay、纽约、芝加哥、丹佛日历去重后有 4,176 个 1h 目标机会。1km 阈值仅 Denver 有三个正例；不同站点、阈值和视图不能相加作为独立天气过程。相关块对间隔参数敏感：0/24/72h 间隔下为三个，168h 下为两个，尚未证明独立天气过程数量。

四区域补充下载 2024 年 12 月原生 TAF/METAR。拟合区间为 `[2024-12-01, 2024-12-19)`，校准区间为 `[2024-12-23, 2024-12-29)`，按完整输入与未来参考窗口清除边界样本，并拒绝跨用途共享同一原生 TAF 版本。2025 年已暴露开发日历用于评价。Bay 的 2025-02-17 至 23 日确认周保持未打开。

基线依次比较原始频率映射 B、独立校准 f(B) 和加入合法证据的 f(B,E)。TAF 的条件段不是官方事件概率；这些映射明确标为研究基线。历史可用时间仍是声明的档案延迟情景，不能当作历史首次公开时间的证明。

四区域 3,303 次原生获取已全部完成。清除边界重叠后，拟合共 9,678 条、校准 2,780 条。5km 的独立校准在四区域本次开发切片上都降低了静态损失，但加入 E 只在 Chicago 和 Denver 继续降低；1km 校准在该开发切片上均变差。未据此替换或重选正在评价的基线银行。

## 正式 API 试点

后台执行顺序：训练获取与解码 → 完整切分清单 → 区域基线 → E 诊断 → 连续 F 试点。工程放行文件已写入；进入下一阶段还必须满足上游数据门槛。日志记录完成或失败，不自动重试模型调用，不覆盖已冻结的实验。

E 诊断在每区域、阈值、合法可见 E 状态下按固定哈希最多选两个底层问题，比较三种证据条件、完整/聚焦输入、直接/逐槽输出以及两个模型。上限 1,200 次、保守费用 3 美元。它是状态分层的小规模开发诊断，低于总路线的 200-500 个底层问题目标，不估计自然部署频率。

连续 F 试点使用纽约、芝加哥、丹佛的 2025-01-06 和 01-10，1km/5km 两阈值，各保留三个站点的 24 个逐时 cutoff，共 12 个案例、每案 72 个机会。每案运行 10 个程序对照和四个模型会话：两模型分别做固定批量证据下的预测器，以及程序预测器下的 LLM selector。最多 2,304 次 API 请求、保守费用 12 美元、同时最多四个 HTTP 请求。

所有方法拥有相同完整 TAF。FOLLOW、COPY_CURRENT、COPY_BASELINE、固定批量、风险、覆盖以及固定 selector 的分配×授权 2×2 均保留。这次 F 试点只采用 `base_bound_override`；持续覆盖协议及逐槽 E 到 F 的新联合输出头仍是后续实验。实际 API 客户端等待时间与声明的来源/程序延迟分别记录，不能声称物理部署总成本完全相同。

费用按已保存官方峰时价、输入全部视为未命中缓存计算保守上界，可能高于实际账单。未知请求保留预留；没有结果重试。原始 JSON 响应、无效回答和失败均进入固定分母。

CCI 的实际 cgroup 配额仅 2 核/8GiB。程序重放迁移至 ACP 纯 CPU 任务 `pt-rky4xj1b`，已核验 64 核/256GiB、0 GPU。原 CCI 的 18 条程序轨迹完成并保留，余下 102 条未启动轨迹使用 32 个程序进程；全部程序通过后再以原定 4 路并发执行 48 条模型会话。冻结代码、数据、模型配置、预算和单次请求规则不变；迁移和原进程真实退出记录见 `runtime/cpu_handoff_01/`。

原定普通日历试点没有 1km 正例。另行预登记 `RARE_MECHANISM_EXTENSION.json`，在普通试点完成后运行 Denver 的 2025-01-09 完整日：144 个两阈值目标机会，其中 1km 有三个正例、5km 有 11 个正例。该批最多 384 次 API 请求、保守费用 3 美元，并保持最多四个同时请求。它是按已知结果选择的单日机制诊断；不能估计自然发生率，不能与普通日历数据混作总体分数。选择信息和未来标签不进入模型请求。

## 温度连续链

使用已审计的 EUPP 原生 51 成员日极值和 DWD TXK/TNK，在 2017、2018 年每季度首月的第 2-8 日构造八个日历窗口。事件为高温日、霜冻日、冰日和两个固定阈值的连续三日事件，不直接命名为符合地区气候学定义的热浪或寒潮。

同一目标保留多个起报时刻的连续版本，共同免费输入是该站点完整的未来四日成员日极值产品。三日概率按同一成员计算，排除已经发生部分的 day0。程序比较 FOLLOW、COPY 最新值、COPY 当前值、首次预报保持，以及两种修订协议。

初次 COPY 接线触发禁止回填已处理时刻的检查，失败记录保存在 `temperature_stream_01`。修正后的新批 `temperature_stream_02` 复用原来已成功的 16 条 FOLLOW 轨迹，只重做失败的 COPY 轨迹，所有来源和初次失败保持可审计。温度这一阶段是 F 程序链，不是 LLM 温度预测或 C1 补充取证实验。

## 模型选择

GLM-5.3 官方 ModelScope 目录、配置和权重索引均已实际下载。当前公开 FP8 版本有 141 个分片，索引给出的权重总大小为 755,617,140,416 字节，超过四张 80GB H100 的总显存，尚不包含缓存和运行开销。因此本批使用已验证可调用的 DeepSeek；其他量化或 CPU 卸载方案需单独验证，不先下载全部权重。
