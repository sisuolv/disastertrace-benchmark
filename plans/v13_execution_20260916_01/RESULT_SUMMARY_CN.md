## 本轮最重要的研究发现

1. **旧的数值结果没有因本次已核查边界而改变。** 原 Stage C 的 LLM selector 仍不能据此声称优于强程序；217 个无效输出保留。修复不会事后重写旧答卷。
2. **对照的解释有一处实际修正。** FOLLOW 直接沿用基线，与 native values 程序是不同消费者。84 个会话级配对原来没有被名字启发式正确标记；新指纹逐因素列出区别。
3. **旧动作空间在关键公开维度上对称。** 288 次请求的三个候选具有不同站点/来源身份，但费用、资料年龄和服务目标数量均无差异。这不足以充分检验复杂预算分配。有效回复仍是 58 次空选、13 次原顺序全选。
4. **拟合与应用时钟确有数值差异。** 固定抽样 24 个目标，保持信息不变、仅把 cutoff−600 秒改成实际 slot，概率绝对变化约 0.0001903—0.0017387。实际新增披露带来的变化另计，为约 0.0005827—0.0632340；其中 1 个目标更换了 TAF 版本。这不是预测收益或显著性结论。
5. **旧 API 回执不能补出未记录的证据。** 288 份未脱敏正文与原哈希匹配，但旧格式未记录最终派发许可和原字节 EOF；290 次历史请求不能追认成 v2 完整生命周期验收通过。也没有因此推断它们一定迟发。
