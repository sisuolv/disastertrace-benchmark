# 全计划数据集的实际补缺与使用方案

日期：2026-09-12。目标是尽量利用原计划的所有候选，同时明确每种数据能支持什么研究结论。

## 本轮结果

固定登记的 **97 个来源/产品/交付入口**中，目前 **84 个有已解析目标样例、6 个可作事件或派生目录、4 个仍待账号/许可、3 个仍未取到目标数据**。97 不是独立数据集数量；84 也不是已经建成的预测任务数量。目录可以用于事件定位，无需强行把目录变成像元真值。

本轮补齐 9 个此前未完成的条目；其余复用已冻结的原始资产。实际完成 84 次批次请求及 9 次 CAMELSH 区间请求，共 **93 次逻辑数据请求、975,066,949 字节响应正文**。其中 78 次以 HTTP 200/206 且 curl 0 完成，但包括元数据和代码，不能当作 78 个成功科学数据集。失败、超时前缀和负例均保留。重定向和软件依赖安装不计入该逻辑数据请求数。

## 如何尽量使用全部候选

按任务中的实际角色组织数据，而不是要求每个来源都进入同一个模型提示：

1. **未来预测与决策主线。** 专业预报为共同基线，观测/事后参考用于自动结算。优先承接已跑通的温度、美国 TAF/METAR、连续流量历史链；气旋和其他灾种补同事件、同目标窗配对。
2. **原生感知与多模态诊断。** SAR、光学、雷达、气旋图像和图文 benchmark 用于验证提取、配准、跨表示及来源重复。没有发布时间或未来结果时，单列诊断任务。
3. **事件索引与分层抽样。** EONET、GDACS、HANZE、Dheed、CLLMate、NOAA 损失事件目录用于定位过程、过滤非天气事件及检查偏差，不把派生目录当独立真值。
4. **条件扩展。** 尚未获得的 7 项保留候选与替代路线；核心试验不以这些来源全部开放为先决条件。

[使用策略](USE_POLICY.json)逐项保留上游关系：MRMS/MESH/QPE、USGS/CAMELSH、METAR/IEM/GHCNh、NHC/HURDAT2/IBTrACS、S1/S2 与 GEE、CEMS 与其派生 flood benchmark，以及 GWIS/EFFIS。相同数据经不同渠道出现，可用于重复证据实验；不能增加独立来源数或作为投票独立性依据。

## 16 类灾害的覆盖情况

保留热带气旋、温带风暴、雷暴大风、龙卷风、冰雹、强雷电、极端降水、洪水、风暴潮、高温、寒潮、冰雪/冻雨、干旱/闪旱、沙尘暴、浓雾/低能见度、天气相关野火/火险。各灾种的数据组合见[逐灾种表](usage_02/HAZARD_CHAINS_CN.md)。

当前覆盖深度不同，尤其要注意：

- 强雷电有 GLM 观测样例，但未确定同目标的专业雷电预报，不能声称完整预警链已建成。
- 低能见度有历史链，不代表浓雾链；Denver 的低能见度正例与雪有关。
- 冻雨与沙尘已有历史现象正例，仍需对应历史预报；雪盖、SWE、冻雨分别定义。
- 火险指数可获取，但火险、起火、蔓延、烧毁范围是不同目标。
- 多个洪水视觉样本来自同一激活/过程，不能用瓦片数量夸大独立事件数量。
- D46 Landslide4Sense 的降雨诱发成因尚未确认，仅保留外围方法/感知参考，不扩充第 17 个正式灾种。

## 对 novelty 的实际意义

本轮加强的是数据支撑，尚未产生新的模型收益结论。后续实验围绕三个可证伪的问题：

| 研究问题 | 此轮补强的数据条件 | 必须通过的检验 |
| --- | --- | --- |
| N1：相同最新专业预报下，额外取证是否改善未来风险判断 | CAMELSH 时间序列、TCIR 时序、多模态洪水证据和可获取的火险数值 | 固定专业预报与预算；与不取证、固定查询及合理简单基线比较；原生证据须同事件、截止前可用 |
| N2：模型是否识别同源重复、表示差异与旧版本 | GWIS/EFFIS 共享后端及多个派生 benchmark 的明确上游链 | 保持底层信息相同，改变重复/表示/版本；不能把同一文件两个接口当新增信息 |
| N3：在截止与成本约束下，错误来自获取、感知、状态还是决策 | 有真实配对的 SAR/掩膜、图文/标签、数值时序，以及留存的获取失败 | 预注册有界干预与失败分母；比较完整流程和各环节上界，不用观察到结果后挑例证明优势 |

既有 LLM 最小闭环的“主动策略总查询官方预报、未显示额外获取收益”仍成立。本轮没有新模型调用，不能用数据下载成功改写这个负结果。实验优先历史回放，无需等待真实未来天气；历史发布时点仍须证明，或明确标为受控回放时钟。

## 仍未取到的 7 项

| 来源 | 当前障碍 | 可继续推进的替代路线 |
| --- | --- | --- |
| EM-DAT | 本机没有已授权数据库样例，需个人注册/使用许可 | EONET、GDACS、Storm Events、HANZE、NOAA 损失目录；用途不是一对一等价 |
| xBD | 仅作者公开图，缺原始影像/损伤标签及获取资格确认 | SpaceNet 8、FloodNet、CEMS 影响产品 |
| HKO-7 | 原始雷达/掩膜需机构成员承诺书及机构邮箱申请 | SEVIR、NEXRAD、MeteoNet；地域和目标不同 |
| ESWD | 研究/批量访问许可与交付方式未落实 | Storm Events、SPC、TorNet；不能据此声称欧洲覆盖等价 |
| M4Fog | 作者网盘未取到原生多通道 cube | ABI + TAF/METAR；DAWN 仅视觉补充 |
| MSETCD / MSCAR | 作者网盘原生数据未取到；参数文件不是数据集 | TCIR、Digital Typhoon、NHC/IBTrACS |
| CMA Best Track | 官方页面及年份文件返回 468 挑战 | IBTrACS/HURDAT2 支持部分任务；不能替代本产品的独立访问验证 |

NASA、CDS/ADS/EWDS、GEE 的已经记录的成功样例没有被旧授权失败覆盖。这里没有新的统一授权需求；剩余 7 项分属不同许可或交付障碍。

## 校验与复现

`audit_recovered.py`负责实际解码，`build_usage.py`负责从冻结登记生成使用清单，`verify_delivery.py`不导入解码器，独立核对源文件哈希、完整 TCIR gzip/成员、部分实际数值和配对约定。最终记录见[验证说明](validation/README_CN.md)。

下载代码为 `fetch_batch.py`、`fetch_public.py`、`rangefile.py`、`sample_archives.py`，查询参数为 `SPEC_01.json` 至 `SPEC_15.json` 及 `CAMELSH_ZIP_SPEC.json`。有界失败和成功都写回执；每主机串行、全局最多 4 个网络请求。已有捕获目录不能直接重跑覆盖。
