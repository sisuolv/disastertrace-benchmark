# 16 灾种的数据组合与准入缺口

这是基于真实取样的候选组合，不代表 16 类均已建成闭环。`extra_evidence` 仍需证明在同一地点、有效窗和截止前可用。

| 灾种 | 专业预报候选 | 结果/代理参考候选 | 补充证据/感知候选 | 最关键缺口 |
| --- | --- | --- | --- | --- |
| H01 热带气旋 | D01 | D02, AW-HURDAT2 | D03, D04, AW-ABI, D38, D50 | 已有窄气旋链；TCIR 与公告/未来强度需同气旋同窗匹配，94 ID 不等于已配齐 94 条链。 |
| H02 温带风暴/非对流大风 | D28, D67, AW-GEFS | AW-GHCNH, AW-METAR, D05 | D48, AW-ABI | 区分持续风/阵风、站点代表性及对流/非对流过程；需真实强风正例。 |
| H03 雷暴大风/下击暴流 | AW-SPC, D67 | D05, AW-GHCNH, AW-METAR | D06, D08, AW-ABI, D49 | SPC 区域概率与站点/报告目标支持不同；需对流归因与漏报规则。 |
| H04 龙卷风 | AW-SPC | D05 | D07, D08, D06, D49 | TorNet 现有样例为负；需有事件身份的正负雷达窗口与报告时刻匹配。 |
| H05 冰雹 | AW-SPC, D67 | D05 | AW-MESH, D08, D06 | MESH 的局地参数表/负代码未完全准入，雷达雹径不能等同地面雹径。 |
| H06 强雷电 | 尚未确定 | D10 | D06, D08, AW-ABI | 只有短 GLM 观测；缺同目标专业雷电预报及极端密度定义，先做受控感知/时序诊断。 |
| H07 极端降水 | D28, D67, AW-GEFS, AW-WPC | D26, AW-GHCNH, D29, D30, AW-QPE | D08, AW-ABI, D59 | 累积起止窗、0/缺测/trace、产品单位与质量；上一轮严格雨量参考仍有未结算项。 |
| H08 洪水/山洪/城市内涝 | AW-HEFS, D57, AW-GLOFAS, AW-EFAS | D56, D71, D11, D18 | D14, D64, D17, D16, D12, D13, D15, D51, AW-NIMS, D42, D43, D60 | 连续流量已有窄闭环；水位与流量阈值分开。D18 新样本为野火，尚不能证明洪水 AOI；SAR 还需截止前观测。 |
| H09 风暴潮/沿岸淹没 | AW-OFS, AW-PETSS | D37, D69 | D58, D01 | 潮位基准、模型位置与站号未完成桥接；P-ETSS 样本明确不适用于热带风暴。 |
| H10 高温/热浪 | D28, D67, AW-GEFS | D26, AW-GHCNH | D25, D34, D47, D48, D62, D66 | 温度历史窄链已配对；热浪需多年气候态/持续性，LST 不能替代 2m 气温。 |
| H11 寒潮/低温/霜冻 | D28, D67, AW-GEFS | D26, AW-GHCNH | D25, D47, D48, D66 | 已有低温参考，需下降幅度/持续性定义；气温不能直接断定作物霜冻损害。 |
| H12 暴雪/积雪/冰冻降水 | D28, D67 | D26, AW-GHCNH, AW-IEM, D55, D33 | AW-ABI, D63 | 已有 FZRA/FZDZ 历史正例；需对齐冬季预报。SWE、雪盖、新降雪及冻雨分别建任务；WPC 冬季产品尚未验证。 |
| H13 干旱/闪旱 | AW-CPC | D31, D32, AW-SMAPL4 | AW-EDDI, D25, D30, D52, D62 | 季节展望不能直接当下周 USDM 概率；闪旱需长期变化定义、质量与无泄漏历史窗。 |
| H14 沙尘暴 | AW-CAMS, D28, D67 | AW-IEM, AW-METAR, AW-GHCNH | D35, D36, AW-ABI, D63 | 已有历史 DS/BLDU 报告；AOD/AI 不直接等同沙尘暴，需同期 CAMS 与地面现象/能见度。 |
| H15 浓雾/极端低能见度 | AW-TAF, D28, D67 | AW-METAR, AW-GHCNH, D27 | AW-ABI, D63, D53 | 美国机场低能见度窄链已配对，雪导致的低能见度不等于雾；保留 TEMPO/PROB、严格单位阈值，M4Fog 原生数据未得。 |
| H16 天气相关野火/火险 | AW-GWIS, AW-EFFIS | D23, D24, D18, D65 | D19, D20, D21, D22, AW-ABI, D43, D45, D28, AW-GEFS | 数值火险入口已可用但共享上游且无历史签发版本；FWI 不等于起火概率，火因/观测缺测及未来蔓延标签须分开。 |
