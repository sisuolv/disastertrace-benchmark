## 4. A1 / P1：完整周 E 可判定数漏掉 supported

位置：`plans/v11_execution_20260915_01/fullweek.py::audit`；本次也读取正在使用的冻结副本 `fullweek_02/source/fullweek.py`，两者Git blob相同：`c2f9c3877f5e3c1236a4c595ac87b91544efbe52`。

实际逻辑：

```python
"e_determined": sum(r["e_status"] in {"entailed", "refuted"} for r in values)
```

上游`policies.py`将`exists_report_support()`结果原样放入`frames[*].e_statuses`；此函数返回`supported/refuted/undetermined/inconsistent`。`audit_case()`也没有将supported转成entailed。

反例：实际证据模块产生supported和refuted，再附unknown/conflict状态。汇总器得到`e_determined=1`，应为2；同一合成组的Brier仍为0.25。

后果：肯定支持被漏计，E覆盖率可能偏低，进而误导C2解释。该表达式不写预测、结果或loss，不直接改变Brier。真实受影响数量须在ROWS和回执完整后计算；当前提交没有完整周最终汇总，不能猜实际漏了多少。

最小修复：按该字段的生产语义统一计数；未知状态显式报错。不同任务里的`full/partial`、`entailed`不能不加区分地全仓库替换。保存原始ROWS、各状态直方图、原E计数和修订计数；核对Brier/分母/概率全部不变。

运行保护：冻结运行源不可热修改。开发源修复后，从原ROWS和日志生成新的只读派生审计目录。若旧自动审计仍在执行，让原有限运行保留原记录；修订报告绑定原输入哈希和新审计代码版本。不为修一个指标重跑840轨迹或模型。

## 5. A2 / P2：年度样例失败分支重复拼接结果

位置：`annual_catalogs.py::execute`：

```python
results = sample + (list(pool.map(...)) if sample_ok else sample)
```

当3个样例中2成功、1失败时，后续月份不会获取，这是正确的；但结果被拼成6条，`completed_units`变为4。模拟执行记录确认实际只调用3个样例，错误是摘要重复，不是自动重复HTTP。

当前真实三个样例全部成功；71/72来自后续Chicago2023-01的KORD失败，不由这个分支触发。因此不能据此说当前71个完成数被虚增。该路径的`passed`仍为false，不会把72个月宣称全部通过。

最小修复：失败时追加空列表，最终按唯一unit核验样例和结果，拒绝重复而不是用覆盖掩盖不同结果。加入样例失败、样例全成功且后续失败、全部完成三组测试。原失败回执和旧摘要不覆盖。

年度失败恢复：原KORD两次尝试已消耗当轮重试范围；补取需要单独、有限、登记的修复范围，只补那个失败切片，复用同月其他5个已核验切片。不能通过重置claim重新获取所有月份。

## 6. A3 / P2：原始最高温概率仍与完整EMOS/ECC产品资格混在一起

`temperature_contract.event_values()`校验所需的未来日与目标变量数组。`feature_tasks.temperature_ensemble_probability()`使用它；`temperature_postprocess.event_probability()`使用它后又调用`validate_products()`，后者强制所有提供日期同时有min/max数组。

合成未来完整UTC日，最高温成员[29,30,31,32]，事件>=30。没有不相关最低温字段时，前者算0.75，后者抛`KeyError: forecast_min_members_C`。

这是剩余接口资格不一致，不是上一轮的非午夜/重复日期漏洞没有修复；后两者本轮已在两个入口同时被拒绝。现有完整EUPP产品含两个字段，未发现旧分数因此变化。

处理：将“原始目标概率”与“EMOS/ECC完整产品处理”分别命名与验证。原始max任务只要求其实际使用的max字段；ECC仍要min/max并完成成员、时段和产品资格。若某个正式任务就是完整产品合同，应在调用前显式校验，不能让独立算概率的函数悄悄扩大依赖范围。保留独立概率算法，不用一个函数替代全部交叉核验。

另需完成真实member_id、initialization、day_index与日期关系的上游lineage绑定；本轮同一排列不变性测试只检验算法，不证明历史数组各列真实来自同一个成员。
