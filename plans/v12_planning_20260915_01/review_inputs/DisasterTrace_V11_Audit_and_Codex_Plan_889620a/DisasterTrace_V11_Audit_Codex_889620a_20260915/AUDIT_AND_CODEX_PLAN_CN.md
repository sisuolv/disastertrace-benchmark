## 3. 两项源码边界

### 3.1 校准银行的提前校验不完整

`monitoring_fixed_v1/native_feature.py::validate_feature_bank` 将输出值前驱初始化为-1，只检查 `previous <= value <= 1`。负值例如-0.2因此能进入首块。每块自身满足 `0 <= lower <= upper <= 1`，但跨块没有校验源概率区间顺序；输出值递增、源区间倒序的表也通过。[S14]

影响：非法银行可能通过加载验证，在后续概率一致性处失败，或以未声明的查表顺序产生结果。不代表非法概率已经进入主表；当前完整周主分采用raw模式。本次尚未扫描实际所有后校准银行。

最小修复：明确输出值闭区间；按冻结的查表语义检查区间有序、重叠和边界。不要事后任意改变合法间隙的插值/回退政策。先扫描历史是否触发；有影响才新增修订分数，不重生成旧模型答案。

### 3.2 目标资格与完整产品资格仍有差异

共享 `event_values` 已修复非UTC日界、重复日期、NaN/布尔/巨大阈值等旧问题。本次同时确认这些拒绝与同成员三日运算。[S11–S13]

但 `temperature_postprocess.event_probability` 在目标校验后再次要求所有产品都有完整min和max。合法的单日max目标，在max完整而min不存在时，较早的概率入口返回0.5，后处理入口抛KeyError；min为NaN时后者拒绝。该问题不是已知全量数据失效，而是未来max-only任务的资格混淆。

处理：原生目标按真正使用的字段和日期准入；联合EMOS/ECC变换保留全产品严格检查。两条数值计算可以继续独立，避免“共享同一个公式所以永远一致”的伪独立复核。涉及ECC的产物必须明确投影与rank规则，不以相同长度代替成员lineage。

## 5. C2设计必须再精确一层

### 5.1 分开两类干预，保留负对照

当前四个候选分支仅改变邻站METAR查询，而144个E题主要检查共同TAF的覆盖/版本。取得邻站观测，原则上不改变同一份TAF是否覆盖目标时窗。F也不直接消费最终E布尔标签。因此这两者不能自动连成“E判对→F变好”的因果链。[S10]

建议两类独立合同：

A. **共同TAF处理实验**：同一原文、同一已读邻站资料，只改变目标时窗解析、版本选择或字段处理。要区分真实模型错误修复与人为注入错误；任何正确中间量须由当时合法资料支持。

B. **邻站取证实验**：共同TAF不变，选择不同合法观测。E命题对应实际被查询的数值、质量、覆盖或缺槽；F消费对应特征。TAF状态不变是应保留的null。

每个分支登记：`manipulated_component → source/field → feature key → raw/calibrated probability → adoption → settled loss`。若没有真正的计算依赖，记录“无传播”，不继续换prompt直到得到变化。

72个全覆盖题保留为简单控制。对已暴露完整日历先普查自然部分覆盖、取消、订正、缺测、删失和冲突；若富集这些条件，单列诊断集且按语义规则选择，不按最终损失或模型错误筛选。没有真实条件时明确缺口，不合成后伪称自然事件。

### 5.2 同状态必须包括共享机会成本

72个目标前缀来自24个父日会话，不是72个独立天气过程。以真实parent/checkpoint/cutoff去重实际状态；一个分支花掉预算，可能帮助当前目标却损害其他目标。因此同时报告选中目标与整个剩余登记会话的效果，不能把每个目标各自事后最优动作拼成一个可行策略。

继承clock、spent/reserved、授权、缓存、在途操作、共同基线、override、版本和失败规则。当前串行边界下若必须先完成原pending，那么所有分支共享相同的排空过渡；实际分支点变晚必须记录。期间到达的基线和截止事件照常处理，不能在新时刻拿到结果后倒填旧时刻。

先验证no-op续行等于原路径，再运行少量真实操作。替代资料不存在、来不及或费用已耗尽时保留不可行状态。固定候选回放、固定资料预测和完整策略重跑三者分开。[S10]

### 5.3 工程C2不应等全年拟合后才开始

用现有冻结v10后端和已暴露资料即可验证状态继承、合法输入、传播链与可复放。这一工程工作可与年度原文下载并行。新后端固定后，再以新注册做科学比较；不能把两版的结果无声混合。这样既避免全部串行等待，也不拿旧后端管线验证充当新科学结论。

## 7. 实验与参考方法保持克制

先固定后端与预测日程，对coverage做分额/全局×私有/共享四格，再比较同B11的risk、轮询、批量和模型。五组fullweek不是新的全四格实验；不要改写其原意义。

48/day是已有情景，先保留可比性。每天清空付费缓存/覆盖与余额的研究过程，应称按日重置监测，不称一条连续一周会话。真正跨日336信用和缓存结转只能新注册，不热改当前作业。

引入轻量参考系统时，优先廉价事件触发与有限一步/两步选择：当前基线订正、资料年龄、可见缺口、目标截止。可用历史训练拟合保守采纳/收缩，但不保证不伤害基线；测试事件结果不得作为在线VOI或采纳依据。

获取质量诊断固定查询计划或预测器；端到端效率必须支付selector、predictor、处理和等待的真实成本。来源查询同为48不等于总成本相同。不是只有LLM获胜才算成功；全读、FOLLOW或不追加处理最好同样可以发布。

## 12. 论文主张的收敛

C1要证明固定专业资料与后端下的信息、计算与修订效果；C2要以真实同状态干预区分可达、理解、处理、预测和采纳，不只画一张解释图；C3要有不同物理过程和明确资格，不靠16类名称。

最值得推进的不是一再增加模型或字段，而是一个能被原始数据、状态轨迹和独立结果共同检验的发现。工程修复本身不保证novelty，负结果也不自动否定benchmark；关键是它能否排除替代解释并在适当独立总体中复现。
