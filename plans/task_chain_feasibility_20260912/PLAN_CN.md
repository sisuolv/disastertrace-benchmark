# 真实下载与完整任务链可行性试点

开始：2026-09-12。用户要求实际下载数据，检验导师讨论稿能否落实。

目标是补齐任务链并产生可复算的数值示例：同对象的历史专业预报、此前证据、固定未来目标和后来观测。已有来源登记与冻结样本保持原样。所有新选过程均为开发/可行性材料，不作为未见确认集。

优先路线：

1. 温度/降水：GFS 历史业务 GRIB + 站点实际记录，先检查 Phoenix 2023-07-18 高温、Denver 2024-01-13 低温；降水窗口另行核查累计支持后再决定是否能结算。
2. 机场低能见度：实际历史 TAF + METAR。初始窗口为 KSFO 2024-01-05、EGLL 2024-12-27、KDEN 2024-01-13。先查档再确定可配对目标，保留没有低能见度的窗口，不把所选日期预先认作已验证灾害正例。
3. 水文：NRWI4、CRHA2、SCOC1 的实际 HEFS 业务集合 + 同站 USGS 流量，检查短期历史版本及已发生目标；若有合格 NWPS 水位配对另列。水位阈值不用于流量，近期平静过程不充当极端洪峰。

以上均针对已过去的有效时间，无需等待未来天气。时间身份依凭据分别标注受控回放、发行时间或本系统已记录的首次取得时间；文件日期不证明当时公开可用。

执行采用最多四个并行 CPU HTTP 请求。先少量索引/元数据，再按精确 Range 获取完整 GRIB 消息或下载小记录文件。初始工作预算不超过 120 个逻辑请求和 512 MiB 实收文件，单次默认不超过 60 秒；必要的适应性追加另留规格和原因，失败不覆盖。数据获取与匹配无需模型 API 或 GPU。

验收分别回答：原生内容能否解析、时空/单位/QC 是否一致、是否存在可比较的真实预报版本、未来结果能否结算、是否有极端/正常样本、能否构造来源和预算对照。小样本数值比较仅验证计算过程，不证实泛化、概率校准或主动取证必然获益。
