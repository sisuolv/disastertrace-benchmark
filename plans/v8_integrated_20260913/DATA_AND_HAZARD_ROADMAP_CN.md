## 2. 保留的 16 类与来源组合

下表的“来源组合”是总体候选，不表示每个来源都进入首篇论文。每行先准入一个清楚命名的子目标，
再逐步扩展该行其他现象；河洪/山洪/城市内涝不能借一个水位站一起算通过。

| 组 | ID / 灾种 | 优先来源组合 | E / F 切入与核心门槛 |
| --- | --- | --- | --- |
| 风暴 | H01 热带气旋 | NHC；HURDAT2、IBTrACS；GOES、TCIR、Digital Typhoon、CMA 补充 | 同气旋同有效时刻的强度与版本；平均风时长、机构定义、裁剪中心只用当时已知信息 |
| 风暴 | H02 温带风暴/非对流大风 | GFS、GEFS、HRRR；GHCNh、METAR；ExtremeWeatherBench | 持续风/阵风及支持时段分开；非对流成因需额外证据，不能用所有强风站报替代 |
| 强对流 | H03 雷暴大风/下击暴流 | SPC、HRRR、Storm Events；NEXRAD、SEVIR | SPC 空间半径/原生窗口与报告匹配；下击暴流成因独立，报告漏报保留 |
| 强对流 | H04 龙卷风 | SPC、Storm Events；TorNet、NEXRAD | 有事件身份的真实正负雷达窗口；现有负样例不代表强灾害覆盖，父风暴分组 |
| 强对流 | H05 冰雹 | SPC、Storm Events、MRMS MESH；NEXRAD | 地面雹径与雷达估计分轨；MESH 产品负码/参数表、物理时间和未来产品目标明确 |
| 强对流 | H06 强雷电 | GOES GLM；NEXRAD、GOES ABI；持续性/密度研究基线 | event/group/flash 层级、区域密度、连续检测覆盖；缺原生专业概率时进入明确 R 轨 |
| 水相关 | H07 极端降水 | GFS、GEFS、HRRR、WPC、合格站点雨量；MRMS、NEXRAD、IMERG、SEEPS4ALL | 累计与雨率、原生支持/QC/空间聚合；先连续时序，不用日数组替代小时窗口 |
| 水相关 | H08 河洪/山洪/城市内涝 | HEFS、NWPS、USGS；GloFAS、EFAS；Sen1Floods11、SpaceNet8、WorldFloods 感知支线 | 流量/水位/空间淹没分别定义；断面、基准、调蓄、阈值、观测时间支持与来源身份核准 |
| 水相关 | H09 风暴潮/沿岸淹没 | CBOFS、P-ETSS、NOAA CO-OPS、GESLA；NDBC | 潮位基准、站点与产品适用域；非热带适用产品不能替代热带风暴潮预报 |
| 温度/冬季 | H10 高温/热浪 | GFS、GEFS、HRRR、GHCN；EUPPBench、DWD、ERA5-Land、ExtremeWeatherBench | 点温度与日最高/多日热浪分开；本地日界、气候阈值和连续超阈过程 |
| 温度/冬季 | H11 寒潮/低温/霜冻 | 同温度数值路线；ExEBench | 降温幅度、极端低温、霜冻天气与损伤分别定目标；普通负温不够 |
| 温度/冬季 | H12 暴雪/积雪/冰冻降水 | GFS、HRRR、GHCN、METAR；SNODAS、MODIS Snow | 新雪量、雪深、SWE、雪盖和冻雨报告分开；卫星雪盖不替代冻雨/暴雪结果 |
| 干旱/野火 | H13 干旱/闪旱 | USDM、SMAP；EDDI、CHIRPS、CPC、ERA5-Land | 未来产品发布、未来湿度和闪旱速率分轨；周四发布的过去状态不称未来物理干旱 |
| 能见度 | H14 沙尘暴 | CAMS、METAR、GHCNh；Sentinel-5P、MERRA-2 | AOD/AI/沙尘组分与近地天气码/能见度区别；气溶胶柱量不能独自确定沙尘暴成因 |
| 能见度 | H15 浓雾/严重低能见度 | TAF、METAR；LAV/LAMP、GOES | 主线；先版本再覆盖、删失/缺报/结果匹配；1km/5km 不等同英里阈值或窗口最小值 |
| 干旱/野火 | H16 天气相关野火/火险 | GWIS、EFFIS、FIRMS、MTBS；WildfireSpreadTS、Next Day Wildfire Spread | 火险产品、已知火场扩张、起火及其成因分轨；热点不是独立火场，两门户不是独立预报 |

地震、火山等非天气灾害不加入本次 16 类核心。xBD/EM-DAT 等可用于事件索引、灾后影响或独立感知任务，
不能因为能下载就成为预警截止前证据，也不能将灾后影像暴露给事前预测器。

## 3. 同一处理链，逐项给资格

每个拟用来源/产品建立一张来源卡，处理顺序为：

```text
官方来源与条款
 -> 原始对象、字节完整性和内容 hash
 -> 原生字段、时区、单位、缺测/QC、空间与时间支持
 -> 产品版本/订正与合法可用时间
 -> Target / Opportunity / QuerySlot / OutcomeRecord
 -> 共同基线与可计费补充资料分离
 -> E 支持及 F 结果匹配
 -> 完整日历强程序基线
 -> 模型开发 / 独立确认
```

机器字段分别记录 `acquisition`、`decode`、`semantics`、`pairing`、`availability_basis`、
`E`、`F`、`MM`、`D`、`confirmation`。每一格绑定实际证据路径和状态，缺项明确 unknown/blocked；
不可用一个总的 usable=true 隐藏物理合同未核准。

本轮不重新定义旧 A0–A5 阶梯；这些独立字段作为该阶梯的审计维度。任务不能因 HTTP 200、目录索引或
一张 GeoTIFF 可打开就升级到模型可评测，更不能因此算完成 16 类。

## 4. 三个近期必须避免的替代错误

**LAMP/LAV。** 历史 IEM 整点 runtime 不直接等于原生 bulletin 分钟。LAV VIS 是类别；其统计映射属于 R 轨。
LAMP 的 `<0.5/<1/<3/<=5 mile` 和 15 分钟最低能见度是原生合同，不能改名为现有 1km/5km 小时站报任务。
取得当前概率文本不证明历史概率档案及匹配观测齐备。

**H07/SEEPS。** VIL 不是雨率，重叠累计不能直接喂入要求瞬时雨率的短临工具。需要核雨率积分或相邻累计差分、
重置、投影、面积权重与缺帧规则。SEEPS 的站点物理日窗、源 QC 丢失及极端过滤影响尚待核准；它目前保留
名义日窗数值配对资格，不作为主线小时降水的替代标签。

**H08。** 历史 QINE 的时间支持和 regulated/unregulated 必须证实，43 列不能套用当前 44 成员说明。
USGS Approved 标识不自动解决预报侧物理等价，stage 的 ft 阈值不能用于 flow 的 kcfs。自然共享的业务预报
本就应在共同基线中公开；不能把下载同一全区域 ZIP 的缓存节省计作主动补证创新。

## 5. 样本与来源角色

自然连续集决定总体预测和误报评价；事件富集集用于极端理解诊断。选样规则预登记、两者分表，
同一母风暴影响多站/多灾种时保留共同过程 ID。允许普通和零正例日，不能凭模型获胜筛选“有用数据”。

再分析、best track、成熟灾害统计和灾后掩膜通常适合结果/审计侧；只有存在合法历史前缀及可用时间合同
时才可作为输入。GEE、云对象存储、原站 API 是访问路径，同上游不重复计为独立来源。

现有数据足以开展下一批 CPU 合同修复和 H15 完整程序闭环，无需等未来天气或新增账户授权。
更广的灾种与在线采集按独立数据门槛推进；是否形成论文 novelty，最终由任务、强对照与独立结果决定。
