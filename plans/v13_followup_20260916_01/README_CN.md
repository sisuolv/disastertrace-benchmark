| 阶段 | 实际工作 | 登记规模 | 能回答的问题 |

沿用纽约、芝加哥、丹佛，2025 年 3/6/9/12 月四个已暴露开发周，1,000/5,000 米两种能见度阈值。每天预算重置，目标提前量 1 小时，48 次来源信用，公共预测时槽及 base_bound_override 不变。预测目标是未来原生站报定义的能见度事件。所有参数来自既有年度银行；没有新拟合，没有打开 Bay 确认周。

## 必须保留的执行差异

M00 提案中原先的 12 份请求来自旧会话中途。为避免伪造新控制器的历史，本轮保留相同天气日，实际调用各日新控制器第一次提交的请求，只完成一个 tick 后停止。它不是 12 个完整日的模型预测实验；概率仍由程序生成。旧中途 payload、模拟 HTTP 预检、真实 API 三者分别保存。

C00 初版准备脚本将 `parent_candidates` 错读为 `parents`，在材料化前退出；失败记录保留。随后发现零步父状态边界，停止尚未派发任何真实调用的辅助作业 `pt-ol1i47dv`，平台返回 `SUSPENDED`。它不能恢复或重新提交。`runtime/c00_m00_02/HANDOFF_FREEZE.json` 记录接续，新脚本 `c00_02.py` 使用 `C00/REGISTRATION_02.json`。M00 原始请求合同和全部 case 均未改动，接续前没有 case claim 或 HTTP 请求。
