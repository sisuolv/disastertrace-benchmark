## 来源与验证

- [输入 manifest](INPUT_MANIFEST.json)：七个原文件的副本和哈希、五个 ZIP 的全部成员哈希、两份重复 Markdown 的对应关系。原件副本在 [inputs](inputs/)。
- [257 条候选记录](SOURCE_CANDIDATES.json) 和 [可读来源索引](SOURCE_INDEX.md)：全部原 ID/原字段保留；独立产品身份待核对，不能称为 257 个独立来源。
- [本地基线快照](BASELINE_SNAPSHOT.json)：当前源码/文档指纹与 MM-4 的 1,130 文件一致性核验记录。本地最新产物不能只用旧 Git HEAD 代表。
- [规划一致性报告](PLAN_VALIDATION.json)：输入字节、记录映射、工单依赖、预算算式、文件链接和本地基线的一致性；不证明新 benchmark 已实现或外部端点已经可用。

可重复运行只读验证：

```bash
python3 validate_plan.py
```

从本目录执行即可；脚本不联网、不推理、不修改被验证文件。若需要保存新的验证输出，请写到新文件，保留原报告。
