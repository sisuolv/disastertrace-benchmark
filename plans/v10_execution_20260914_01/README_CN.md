## 总体路线

研究问题保持 C1/C2/C3：共享资源下何时值得获取更多资料；当前证据的可判定性与未来
预测价值如何分开；这些机制能否在不同真实天气过程中复现。16 类灾害仍是数据路线图，
逐灾种的 E/F/D/MM 资格单独审计，资料可下载不等于完整任务准入。

1. **N1 测量可靠性**：审计注册全集，统一终态，严格解析，保全费用与失败，正式入口绑定
   来源结果政策、运行身份和版本。新增反例先运行失败，再修复；旧源码快照和结果不改。
2. **N3 可解释的 E/F 接口**：用原回答计算逐槽程序汇总；记录原始频率单元、回退、校准家族
   和输出概率；检验两阈值一致性与校准支持；保留原模型分数及原银行。
3. **N4 有限机制实验**：固定证据比较预测器，固定预测日程比较取证；多截止同目标比较
   FOLLOW/COPY/KEEP、两种覆盖协议和预先声明的采用规则。新模型批次只回答尚未解决的问题。
4. **N2 独立性与确认**：补输入、共享资产、版本、目标窗口的完整依赖；自然日历和 Denver
   已知结果选日诊断分表。先形成确认合同和冻结清单；本轮不打开 Bay 2025-02-17 至 23 保留周。
5. **N5 跨过程与交付**：复用两年温度原生数据，补强概率对照及合法补充证据；MRMS/HEFS
   先核物理量和时间支持。D、原生 MM、联合目标、前瞻提交分别过门槛，不阻塞核心工程交付。

| 阶段 | 本轮动作 | 出口证据 |
|---|---|---|

| T04 | 多截止与持续覆盖的 CPU 程序对照；费用/输入依赖审计 | 新运行身份、全部机会、状态差异和成本 |
| T05 | 条件合格后冻结并运行一个有限 E→F 模型试点 | 新请求预算、原始回答、失败账本、同信息强程序对照 |

T00--T03 优先保证完成；T04/T05 按真实出口继续，不把尚未运行写成完成。
模型试点不以正收益为启动或继续条件；必要的数据、接口、成本和测量资格必须通过。
若旧 f(B,E) 仅消费逐槽计数，单独修正最终布尔汇总不会改变 F；必须如实测量并说明。

## 并行与加速

CPU 审计按会话/月份拆分为独立进程，重用上一轮已验证的相同评分器并行重放方案。
共享 AFS 上避免反复序列化全状态；每个任务生成有限、可恢复且不可混淆的证据。
模型需要时使用最多 4 H100；也可申请 GPU 节点的 CPU 做实质计算。所有任务有独立目录、
有限工作量和终态回执。长计算由后台脚本执行，在完成、失败和里程碑检查。
