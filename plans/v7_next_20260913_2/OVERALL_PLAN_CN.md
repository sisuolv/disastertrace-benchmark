## 1. 总体判断与研究目标

建议把整体目标固定为：

> 在共同专业预报或明确标注的研究基线持续更新时，评测 LLM/VLM 能否根据天气目标、
> 可用证据、时间和资源约束，选择值得获取与处理的信息，及时修订预测并完成研究性准备。
> 用证据支持集合、共享预算内的联合可达性、同一完整状态的分支重跑以及同天气的准备需求配对，
> 检查增益或失败来自哪里。

第一篇机制研究聚焦少量深入场景；完整 16 类是总体数据和发布路线。两者共用合同和引擎，
但采用不同验收等级。无需等未来灾害才能做历史研究，也不依赖逐题人工复核或 LLM judge。

新增准备任务 D-sim 是有持续时间、资源占用、取消与沉没成本的状态过程，不能只在回答中
增加一个“采取措施”字段。它是明确研究规则下的仿真，不能解释成已减少现实损失或伤亡。
天气预测 F 继续独立评分，D 的成绩不能替代 F 成绩。

## 4. Novelty 的完整证明路径

| 贡献 | 明确研究问题 | 需要交付的证据 | 不足以证明它的结果 |
|---|---|---|---|
| C1 | 共同预报持续更新时，额外资料、处理深度、分配和修订/准备是否值得成本？ | 相同权限与预算、强批量/工具/调度基线、实测成本或声明情景、全机会损益 | 更多工具调用、缓存节省、自动回退或弱基线 |
| C2 | 当前合法资料能确定什么？哪些目标能在同一预算内共同确定？错误与后续 F/D 有何关系？ | 真实产品支持规则、同路径可行见证、分项 E、完整状态分支、结果侧隔离 | schema 通过、解释文本、特权 mask、各目标独占全预算的最优值相加 |
| C3 | 这些合同、方法及适用边界能否跨物理过程和独立时空块复现？ | 第二过程、冻结确认、分层缺失、来源/许可与可复现包；前瞻单列 | 多站、多阈值、多 seed、数据源数量 |

两项重点新增实验：

**同一完整状态，改变下一步取证或处理。** 固定已花/预留资源、版本、缓存权限、在途任务、
策略记忆、外部档案和继续策略，从同一前缀分别等待、查站报、处理区域影像、调用领域工具等。
它给出声明环境中的事后路径差异；不能把后见最好分支当可部署策略或单样本期望信息价值。

**同一天气，改变准备要求。** 固定天气目标和资料，分别改变准备时长、容量或成本。
固定信念实验中 F 不接收偏好字段，D 接收；这是软件隔离检查。另设端到端模型行为试验，
检查偏好是否污染概率。若不同需求导致合法获取了不同资料，则最终 F 不同可以是合理的。

“信息价值依赖用途”、成本损失、主动特征获取或调度本身不是首次提出。论文差异应由上述组合的
真实任务、严谨对照和独立结果建立。本轮没有联网完成新的文献查新；附件中的论文阅读结论不自动升级为本轮复现。

## 5. 一套体系，分别评价 E / F / D / MM

```mermaid
flowchart LR
    A[真实档案与可用时间合同] --> B[唯一会话时钟与资源账本]
    B --> C[合法获取和处理]
    C --> E[证据支持 E]
    C --> F[独立天气预测 F]
    F --> D[研究准备状态 D]
    E --> R[分别评分与完整分支复放]
    F --> R
    D --> R
    M[同源原生图像或工具表示 MM] --> C
```

### 5.1 目标与时间

- `Target`：对象、变量、空间支持、单位、点/区间、阈值、结果身份与版本政策。
- `Opportunity`：同一目标可以有多个预测截止；某机会封存不结束该目标其他机会。
- `DecisionSpec`：准备截止、时长、容量、有效期、成本、取消及研究假设；其变化不改变天气 target hash。
- 区分物理未来、未来产品发布、已部分发生窗口的 nowcast；USDM 等产品描述时间与发布时间分别记录。
- 历史情景回放、文档核准的历史可得、真实 first-seen 前瞻分轨。历史抓取时间不回填为当年发布时间。

正式 F 路径固定为：`机会 -> 合法 cutoff -> 日志前缀回放 -> 有效预测 -> 固定成熟结果 -> 评分`。
迟到、无效、解析失败保留机会并按冻结回退规则处理，不按方法删题。纯离线数值表仍可独立计算 MAE。

同刻规则提议：沿用旧轨相位和 cutoff 解释；新增准备占用为 `[start,end)`，已合法 START 的作业在
`completed_at <= ready_deadline` 且准备覆盖包含需求时刻时算及时。覆盖恰好过期不算保护；截止时
新开零时长任务不获得信用。最终顺序在 CP00 的 ADR 中冻结并用对抗事件表验证，不能靠 Python 调用先后决定。

### 5.2 证据与联合参照

E 分三种资格：公开可认证产品/测量事实、原生感知评价、特权标准事实诊断。原始影像的交付
不代表隐藏 Gold mask 已成为模型知道的事实；工具估计不自动成为精确测量。

首批真实 E：TAF 条件覆盖/继承、站报删失或缺槽、同目标版本替代。邻站存在命题保留作回归。
H07 累计缺段另接支持区间；无合同上界时保留正无穷，冲突空集返回 inconsistent，订正重新建支持。

现有 `heads.py` 还限制航空目标及邻站存在谓词，F-only 也经过该检查。provider 支持新 E 不等于
模型接口自动支持新 E；需按任务版本新增 head/prompt/validator 与评分映射，不能只替换 E_question。

`solve_joint` 复用现有有限图算法，新增真实 provider 编译和独立见证复放。只能回答同一预算、并发、
截止下可共同认证的 E 集合。最低费用和最早时间必须来自同一路径或明确 Pareto 前沿；搜索截断报告界。
该 E 参照不是最优 F/D，不能因 E 未取全就把合理资源分配计为失败。

### 5.3 动作与成本

初版有限动作目录：获取、处理、领域工具、预测、提交、FOLLOW、等待/停止；D 另有开始准备、取消和释放。
队列规则先固定，不首轮加入任意跨地点迁移、免费暂停恢复或复杂救援。

四张账分别记录：研究构建档案、策略获取、处理/模型、准备执行。所有 selector 调用也计费。
源文件共享只免已支付的相应费用，重新渲染/模型读取仍收费；物理缓存和策略授权是两件事。
实际工作量、并行 wall time、排队时间和历史声明时延分开。按目标分摊不得再次加进物理总成本。

保留全部必要身份：输入 bundle、模型可见视图、上游版本、目标相关基线上下文、评估器 checkpoint。
它们解决不同问题，不能强行合并成“三种 hash”。基线语义指纹不能仅取一个概率值或整个无关 envelope。

### 5.4 状态分支分两期

CP04a 先做无在途任务的显式序列化、跨进程恢复和分支；标为 `quiescent_checkpoint`。
先将现有 `run_session` 的循环局部状态整理为可步进、可序列化的唯一协调者；仅恢复 engine/forecast
对象仍会遗漏 selector、逻辑时钟、tick、预算和调度状态，不能直接当完整 checkpoint。
CP04b 再支持预留、在途输入/版本、剩余耗时、准备进度与缓存权限。不用 deepcopy 或仅复制 bundle
宣称任意时刻恢复，也不把 seed 相同说成新 GPU 采样必然逐 token 相同。

第一批每前缀至多 4 个预登记候选、深度至多 2。未归档返回记 `not_evaluated`；记录候选、合法、
实际执行和未覆盖数。研究分支总费用另列；各部署分支分别继承前缀一次，分支后不免费共享新资源。

### 5.5 准备状态与损失

首版每个决策目标一个作业、一类容量资源。跨地点可共享的资源优先解释为远程分析/准备支持能力；
当地设备或人员不无代价跨机场移动。具体名称和研究假设在 scenario card 中固定。

状态至少覆盖未开始、排队或明确拒绝、进行中、完成待用、过期、取消/清理。推理等待不暂停已开始准备；
预测回退不撤销准备；取消不退已耗资源；恢复和重复请求不重复扣费。

研究损失可取：

`J_D = 已开始费用 + 实际工时费用 + 明确取消费用 + sum_i M_i * y_i * (1-ready_i)`。

参数使用研究单位并预先冻结，同时报告各组成，不把工时、token、货币随意相加；同一工作成本不重复计入。
多个 F 提前量不重复收同一 D 目标的漏准备损失。结果未知仍保留已知操作费及未知罚分界。
需求时刻取预登记目标时点/窗口边界，不从事后首次越阈倒推截止。

先固定 F 比阈值、最早截止、滚动优化器与 LLM 行动；再固定行动方法比 F。
小实例用独立枚举检查；需要扩大时接 OR-Tools，目标是合法预测下的研究期望损失，不是照搬 makespan。
完美未来调度仅属评估侧特权下界。无人工规则背书时保持 research_assumption，仍可自动评分。

| H12 冬季灾害 | GFS/HRRR + GHCN/METAR；SNODAS/MODIS Snow | 冻雨报告、新雪、雪深、SWE 分别核验；雪盖不替代暴雪/冻雨 |
| H13 干旱/闪旱 | USDM/SMAP + EDDI/CHIRPS/CPC/ERA5-Land | 未来产品发布、未来湿度和闪旱速率分轨；不把过去状态叫未来物理天气 |
| H14 沙尘暴 | CAMS + METAR/GHCNh；Sentinel-5P/MERRA-2 | 沙尘天气码/能见度与 AOD/AI 产品分轨；现象和成因支持单列 |
| H15 浓雾/低能见度 | TAF/METAR；同期 GOES；LAV/LAMP 独立子目标 | 主回归/首个 E/F/D-sim 场景；低能见度不统一叫雾，LAMP 英里/15分钟窗不能替换小时报告 |
| H16 天气相关野火/火险 | GWIS/EFFIS + FIRMS/MTBS；WildfireSpreadTS/Next Day Wildfire Spread | 已知火场扩张、火险产品、起火成因分轨；热点不等于独立火场，两火险服务不等于独立模型 |

### 6.1 近期不是让 16 条链同时扩张

- **H15 是开发主线。** 最多先固定一个站群、一个连续开发块，复用历史数据与强基线；已暴露日期继续只作开发。
- **H07 是第二机制/原生 MM 的优先候选。** 先小区域连续链预检；当前单次 QPE/MESH 样例不是连续短临链。
  可先做明确命名的未来 QPE 产品累计目标，站点实测单列；同源输入/结果披露依赖。
- **H08 并行核准。** 已有 2024 两版 QINE 与 USGS，不重复下载作进度；先核瞬时/平均、调蓄、断面及单位。
  当前 43 列身份未知，不能按最新 44 成员说明硬拼跨站情景。水文受阻不阻塞 H15/H07。
- **EUPP/DWD 是低成本类型迁移。** 普通温度可接入新会话，尚不能算第二极端天气机制成功。
- **H01 是有条件候补。** 第二过程选择依据预登记合同和覆盖，不根据哪个领域使 LLM 获胜来选择。

H07 首轮单独选择雨率或累计路线：pysteps 需要规则时序且变量/单位合法，不能对 VIL 或重叠小时累计
直接假装瞬时雨率。率积分、重置、投影、质量、缺帧与覆盖先核验，专业工具输出仍是预测。
SEEPS4ALL 保持日界/QC 条件候选；不能拿现成日数组补旧小时目标。

GEE 可作为已有可用的获取/处理后端，固定 asset、集合、时刻、ROI、投影、参数和 hash。
同一个上游的 GEE/原生镜像不算独立来源；历史首次可得仍另证。HKO-7/ESWD/M4Fog/MSETCD 不作主线前置。

每类至少区分 acquisition、decode、semantics、pairing、availability、E/F/MM/D、independent_confirmation。
同一灾种的一个合格子目标不代表该行所有子灾种完成。最终广度报告公开分母和未覆盖的子类型。

## 7. 实验主线与强对照

原 X00--X09 名称及意义以 [既有实验矩阵](../v7_0912_overall_research/EXPERIMENT_MATRIX.json) 为准。

| 原实验 | 本阶段增加的内容 | 必须固定的对照 |
|---|---|---|
| X00 基线/任务审计 | 真实 F-only；比较 B、f(B)、f(B,E) | 同目标、同机会、同结果掩膜、冻结银行 |
| X01 分配/共享 | 同 selector 的 fixed_quota/global_budget × target_private/session_shared；工具选择另子实验 | 同预测器、同权限规则、预算与付款规则；共享私有记忆不泄漏 |
| X02 修订 | 两协议、固定候选门控 | 旧候选与完成时刻不变；端到端重新选择另跑 |
| X03 信息历史 | 真实版本、谱系、同前缀分支 | 自然时序与人为压力分开 |
| X04 支持/可达性 | 三类真实 E、联合见证、E 与 F/D 响应 | E 参照范围明确；隐藏答案不进输入 |
| X05 多模态增量 | 同源表示、领域工具、原生 VLM；新增传感器另条件 | 源资产、ROI、权限、成本可比；特权事实单列 |
| X06 跨过程 | H15 之外的合格机制链 | 普通温度工程验证不替代极端过程确认 |
| X07 时间/资源 | 处理深度、准备时长/容量/成本、固定预测的调度比较 | 实测与声明时延分表，准备损失和 F 分数分表 |
| X08 有限前瞻 | 程序观察器后再有限模型，真实提交/后续结算 | 固定起止、普通机会、失败和未成熟结果 |
| X09 联合目标推理 | 条件扩展，保留联合目标接口 | 同信息总预算；不等同共享缓存或工具路由 |

第一批主要比较只保留三组：固定证据 E/F、真实小会话/分支、固定预测的准备对照。
不要展开模型 × 提示 × 地区 × 预算 × 表示 × 准备参数的全笛卡尔积。

强对手依次建立：共同基线、不补证统计、便宜批量全读、领域工具、变化/风险/覆盖规则、
同工具的滚动优化器、有限一步/两步、LLM。所有程序方法也可使用缓存、批量、并发和专业工具。
有限学习策略只在开发数据和对照充分后进入，不首轮训练大型 RL 或多 agent 群。

同时报告：

`gain_over_model = L(f(B), y) - L(f(B,E), y)`；

`gain_over_baseline = L(B, y) - L(f(B,E), y)`。

模型有资料后修复自己空资料时的 0.5 退化，不等于超过共同基线。无收益和负收益都可发布。

联合风险后置：固定排程的逐目标可加期望损失可能只需边际概率，共享容量本身不证明联合预测必要。
只有非线性共同需求、超容量概率或适当再决策目标才启用 CP14；成员身份和共同结果覆盖必须可验证。
原 X09 的“单目标分别推理与多目标联合推理”可以都输出边际概率，并不必须启用联合分布或非线性损失。
CP14 是新增联合风险子轨，它的前置条件不约束原 X09 的全部实验。

## 9. 统计、自动评分与失败出口

自然连续日历用于总体风险/误报/损失；事件富集集用于极端诊断，分开报告和选样。
父天气过程或保守时空块用于独立分组；purge 覆盖最长回看、目标窗口、提前量和准备有效期。
多个站、阈值、提前量、seed、profile 或分支不增加独立天气过程数。

确认前冻结模型、提示、校准、selector、门控、动作目录、成本/profile 网格及主指标。
样本量依据预先声明的最低有意义差异与独立块不确定性；正例太少时尾部指标报告不可估计，
不能在看到模型成绩后选择获胜日期、银行或灾种。所有现有暴露数据只作开发。

模型执行失败仍按统一规则回退并纳入机会；结果缺失按共同掩膜比较，但还要做风险/地区/来源/质量分层
及适用的敏感性界。共同掩膜不保证总体无偏，E 充分也不强制 F 停止获取。

若文本批量全读足够便宜，保留“主动选择无益”的结果；若 H07 连续变量不成立，保留来源资格失败并推进
H15/H08/EUPP 可独立完成部分；若准备结论仅在特定假设成立，报告参数范围，不能改参数制造 LLM 优势。
