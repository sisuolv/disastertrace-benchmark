# DisasterTrace v7：基于开源评测与近期论文的增量优化补充

审阅基线：`sisuolv/disastertrace-benchmark@98f28a9a9f33c28ec2b0236c4aaf47a9173c813e`，分支 `next-phase-v1`。

## 状态与边界

本文补充现有 v7、C1/C2/C3 和 X00–X09，不另建 v8，不替换已有时钟或账本。本文是研究与实现建议；本次核对了仓库文字和相关官方文档/论文，但没有安装运行外部库、下载科学数组、调用模型、提交 GPU 作业、修改远端文件或运行新测试。以下全部新增适配器、数据准入和实验仍待执行。不得把文献存在或 README 可读计为数据 A1/A3/A4 通过。

保留16类灾害、六组迁移、E/F/D分离、无需新增逐题人工Gold、不用LLM judge作为主评分、旧结果和负结果不变。新增资源仅按原用户授权、明确端点与请求/字节界限执行；历史GPU额度不自动视为新运行授权。

## 2. 航空基线：先核验 LAMP，不将类别公告伪装成概率

官方 LAMP 有能见度和云底等统计指引，部分产品包含原生概率。IEM MOS档案列出 LAV 从2020年7月12日起的部分起报周期，但这不保证指定站点、日期、概率字段和每个子小时周期都可得。NOAA明确说明 BUFR 比 LAV 字母数字公告包含更多概率字段。因此必须先确认实际档案产品，不得把 VIS 类别编码当概率。

准入对象为：`provider + product + version + issued_at + valid_support + threshold + condition + station`。尤其区分：

- `<1 statute mile` 与 `<1000 m` 是不同事件；`<3 miles` 也不是 `<5000 m`。
- 15分钟窗口最低能见度、整小时范围和一个例行报告时刻，不是同一统计支持。
- 给定降水发生的条件概率，不是无条件能见度概率。
- 今天的字段说明不能无核验地套到所有历史版本。

输出 `LAMP_ADMISSION.json`：档案覆盖、实际原生字段、同目标匹配、时间可得性证据、资料许可证/用途、未通过原因。只能取得类别时，设类别专业对照；自己的概率转换继续标为研究映射。原TAF研究轨保留原定义；原生阈值子任务另设ID，禁止将改变目标后的分数与旧分数直接比较。

LAMP已使用部分HRRR信息；同一HRRR产品不应被假定为独立新增证据。记录发布时间与谱系，测的是给定共同参考后直接访问额外资料的条件增量。

## 3. EUPPBench：用于温度与后处理迁移，不等于现成在线监测环境

EUPPBench提供时间配对的预报、回报和参考，并有站点子集。官方站点文档说明，2017–2018年集合/确定性预报与站点观测配对；另有以当时模型重算的历史reforecast。优先选择站点子集，不能误用默认格点ERA5参考后写成实测站点。

借鉴范围：读取插件、站点/有效时间/lead-time组织、集合与确定性预报、EMOS等后处理对照。

不可直接继承的范围：历史真实公开时间、主动取证权限、同资料是否已被共同参考吸收、输入观测的当时修订版、前瞻无污染保证。

适配步骤：
1. 只读元数据和最小合格片段，验证来源、站点、时间、单位、质控与实际字节。
2. 连续日历生成 targets/opportunities，参考记录只进入评分侧；早于截止且合法可得的观测才能进入查询侧。
3. 使用正式 forecast 构建回放；reforecast单列为研究构建/训练材料，不能冒充过去已实际发行产品。
4. 对同一未来有效时刻，可以使用多个合法起报更新；不能将不同 lead-time 对应的不同未来结果伪装成版本修订。
5. 将数值预测输出显式扩为 `scalar/quantiles/distribution`，不把负温度硬塞进概率字段。
6. 与已有GFS—站点链并列验证；哪条先满足连续覆盖和合同门槛，哪条先承担第二领域联调。

这是H10/H11候选迁移，不增加第17类灾害。开放现成benchmark被检查后，继续登记为暴露开发材料；不能直接成为未见确认集。

## 4. SEEPS4ALL：H07的日尺度替代建设路线

2026-01-30发表的SEEPS4ALL论文提供日降水验证资料、站点/月气候统计和验证代码。其示例观测覆盖2022–2024，气候统计基准为1991–2020。ECMWF仓库 `seeps4all/` 下有 `datasets/` 与 `verification/`。

用途：建立日降水子任务的结果侧与气候基准；提供站点气候分位数阈值和成熟的验证方法，减少重复搭建参考数据的工作。

边界：
- 日累计不能拆成小时真值，不能修复旧New Orleans六小时任务的拒收结果。
- 仍需站点真实日界/累计支持与对应业务预报配对；日期字符串不自动等于UTC自然日。
- 当前配对档案不是历史实时交付证明；混合/回顾质控观测首先作为结果侧。
- 新版气候产品可以作为现代回放中的固定背景，但若声称重现当时部署，还须核查该背景当时是否可用。
- SEEPS“heavy”类别不自动等于极端灾害。极端阈值单独按预登记气候分位数或应用阈值定义，不根据测试成绩选择。
- 代码、论文、数据可能有不同许可。仓库README标明数据为非商业用途许可；发布前核对实际版本完整条款。

SEEPS不替代所有任务的Brier，也不用于机场能见度。既有结果与新任务分表。

## 5. 多模态与真实分析成本：用pysteps建立强领域对照

pysteps可提供降水外推、S-PROG、STEPS集合、NWP blending及验证接口。先作为领域预测器/计算工具，而非强行让LLM替代成熟降水算法。

同一合法雷达序列设置：专业/研究参考；pysteps；数值特征+固定融合器；VLM原生图；相同工具库下固定与主动选择。各方法的读取、裁剪、光流、集合计算、模型推理成本单列。

动作可以选择资料范围和计算操作，但不默认增加新层级：接入现有查询/资源账本。建议操作为合法范围读取、固定ROI序列、确定性特征提取、冻结领域模型调用、VLM解释。所有派生资产继承父资料授权；计算所用的源数组不是免费隐含输入。

严格要求：真实降水率/降水量的单位与时间支持；VIL不能直接当毫米雨量；所有邻域目标共享大区域场时检查halo及裁剪边界；输出概率和标签使用相同时间/空间定义；未来QPE可做声明的产品参考，不冒充所有物理降雨真值。

先验证已有资料是否足以形成合法短临链，再决定是否接入更多雷达源。受控按槽位计费可以保留，但不能作为现实稀缺证明；实际服务成本轨允许批量、合理缓存、不紧预算和零调用FOLLOW。

## 6. 以BCEA等工作为依据，校准完整流程而不是只校准基线

BCEA 2026-07-21 v4区分严格认证与实用未认证版本；其核心启示是获取改变得分分布，基线校准不能自动继承给获取后系统。天气具有时空相关性与分布漂移，不直接搬用其独立样本假设或有限样本保证。

开发安排：预测器拟合、selector/gate设计、完整流程校准/检查、确认集四部分按事件/时间块隔离；冻结整个政策后检查其系统概率。模型辅助E事实判断仍与未来F概率分开。自动FOLLOW/失效是系统协议，效应单列。

先做无新增模型调用的候选审计：沿用现有已保存候选概率和完成时间，比较原门控、全应用、规则门控、两wrapper。只得到事后诊断；不能用旧评估日历调门控后当作独立确认。

只有已记录候选轨迹的离线重评分可以直接执行；未选择的动作对应输出不能凭空构造，也不能将日志当成没有覆盖问题的离线策略评估数据。

## 7. 评分改进：不通过改弱标准制造收益

保留原Brier、全部日历机会和结果掩膜。补充：

| 面板 | 输出 | 禁止的解释 |
|---|---|---|
| 概率质量 | Brier、可靠性、适用的CRPS | 低Brier自动等于有效预警 |
| 识别能力 | AP、ROC、固定/开发冻结操作点下的召回与误警 | 测试集上挑最好阈值后称确认 |
| 极端区间 | 多阈值Brier；有完整合格预测分布时twCRPS | 只保留正例或随意正例加权仍称原概率质量 |
| 研究使用情景 | 提前量、去重后的提醒、声明成本损失 | 未做人员/业务研究就声称真实减灾或人工工时收益 |
| 资源 | 请求、字节、解析/渲染、selector/predictor token与时间 | 各单位任意求和为一个总分 |

可对齐 `scores` 或 `scoringrules` 的概率评分实现做差分检查。外部库不替你处理掩膜、CDF合法性、输出模式或事件分组；scores文档特别说明某些CRPS接口不检查CDF单调性，因此调用前必须自行验收。

twCRPS只用于实际提交完整分布/分位数或集合且参考合格的任务；当前航空单个阈值概率不直接套用。阈值权重在开发前固定，保持自然队列，不让极端加权成为事后改变目标分布的捷径。

## 8. AFDBench：借鉴事实核验，不借用写作风格主分或立即训练GRPO

2026-08-25的AFDBench研究专业气象讨论生成，区分数值、风格和输入grounding。其数字集合重合/词汇指标测量的不是固定未来物理结果，不能加入DisasterTrace主分来提高表面成绩。

可以借用的思路：把语言输出拆成有类型的事实，保存 `(entity, variable, unit, valid_support, product_revision, value, receipt)` 并独立核验；生成文字属于可选展示层。核验单个词或数值出现不等于其实体、时间和量纲正确。

本次未核验其官方可运行代码/模型包；仅按论文方法参考。不要为了赶上新论文立即新增SFT/GRPO或LLM judge。

## 9. 不增加新核心假设，映射回C1/C2/C3

- C1：相同强参考与真实成本条件下，选择哪一份证据、哪一种计算、何时沿用/修订，是否优于强批量与简单策略。
- C2：确定性支持、联合可达性与实际F增量分别测量；读懂E但F无增量、改善校准但未改善排序等负结果保留。有限E最优路径不是F的理论上界。
- C3：统一物理/产品/报告身份与不同时间尺度，在H15、H10/H11、H07/H08上实际迁移，再扩展完整16类。

值得检验的是预报更新周期、空间支持、来源依赖、计算操作与截止的交互。单独的“分析工具选择”“选择性预测”“时间回放”已有研究，不单独主张首次。
