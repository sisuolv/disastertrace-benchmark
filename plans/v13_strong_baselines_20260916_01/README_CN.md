# v13 强程序基线：B01 决策与 B02 对照

本轮承接用户的继续执行授权。执行入口是两个已提交的 CCI/ACP 作业，不需要手工重启。运行状态见 `STATUS.json`；完整计算结束后生成 `FINAL_RESULT.json` 和 `RESULT_SUMMARY.md`。文件尚未生成时，不代表相应验收已经完成。

## 已完成的工程工作

- 在读取所选日期的成绩前，使用固定种子与 case ID 的 SHA256，在 3 个地区 × 4 个季度周中各选 1 天。12 个日期及全部 84 个候选记录在 `PROGRAM_ROSTER.json`，主阈值为 5,000 米。
- 新增三个明确版本的选择器：`round_robin_cycle.v1`、`public_risk_age.v1`、`fixed_hash.v1`。旧 `round_robin` 按时刻哈希排序，保持原样；新轮转按公开站点顺序，在每个唤醒和完成取证后轮转优先权。
- 风险策略按一个查询公开关联的目标风险之和排序，再按公开可获取时间排序；这里的时间不是推断出的观测新鲜度。固定哈希不使用风险、返回值或评估标签。它们都没有训练得到的 VOI 估计。
- 30 项选择器与预测时槽定向检查、10 项启动门槛检查通过。随后在远端执行的合并回归覆盖 81 个测试模块、912 个唯一测试，全部通过；包含之前全部 880 个测试，没有遗漏、跳过或失败。
- 13 个旧策略/预算/授权组合在旧、新代码中生成完全相同的报告。旧代码路径的 AST 专门化检查也相同。新旧完整包哈希不同，不能声称字节一致；真实变化限于新增选择器分支及其模块。

## 正式矩阵与可解释的对照

新增 6 个条件，每个运行同样 12 天，最多 72 个程序方法日、5,184 个方法评分行：

| 条件 | 预算分配 | 证据授权 | 查询规则 |
|---|---|---|---|
| B11_RR_CYCLE | 全局 | 会话共享 | 真实轮转 |
| B11_RISK_AGE | 全局 | 会话共享 | 公开风险、公开发布时间 |
| B11_FIXED_HASH | 全局 | 会话共享 | 固定种子哈希 |
| B00_COVERAGE | 固定份额 | 目标私有 | coverage |
| B01_COVERAGE | 固定份额 | 会话共享 | coverage |
| B10_COVERAGE | 全局 | 目标私有 | coverage |

与原 B00 日历中的 `B11_COVERAGE` 构成预算分配 × 证据共享的 2×2。原日历中 FOLLOW、F_COMMON、F_BASE_ONLY、B11_BATCH、B11_COVERAGE 共 60 个方法日，在兼容性和正式评分重建通过后复用，不重复计作独立实验。合计 11 种方法、864 个共同预测机会、9,504 个方法行。

所有新增方法固定使用原年度 raw values 预测器、相同的专业资料流、预测时槽、来源信用和未来站报目标。预测概率由程序生成；本批模型 API 请求为 0。FOLLOW 和 F_COMMON 与 values 预测器的区别继续单列，不把它们混为同一预测器的取证对照。

## 顺序和放行门槛

1. 合并回归及旧策略兼容性检查。
2. 等待上一轮 B00 全部 168 个单元、840 条轨迹通过验收。核验其源文件、输入、全部行身份及所选原始正式评分。
3. 固定银行决策。为隔离查询选择作用，本批沿用年度参数，新增拟合为 0；这不表示已证明时点偏移不存在或重新拟合没有价值。`BANK_DECISION.json` 只在 B00 完整通过后落盘。
4. 在读取新方法成绩前输出公开动作普查，再产生 `GATES.json`，启动两个分片执行 72 个新增方法日。失败保留，不自动重试、换日期或补样。
5. 汇总配对 Brier 收益、正负例、地区/周/日期分层、缺失 Y 的敏感性界和真实查询序列差异。完成后结合 C00 GET 结果判断 M01 的实际可执行范围。

12 次 M00 接口小试全部选择所有查询，因此不能据此声称模型调度更好。强程序排序不同也不自动说明存在有用信息增量；即使零收益或负收益，本实验仍可正常完成。12 天都来自已暴露的开发周，没有独立确认效力。
