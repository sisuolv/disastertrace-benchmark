# DisasterTrace 详细理解版

这份材料面向希望先弄懂项目、再精简研究汇报的读者。正文为 24 页 A4、17 章，包含目录、72 个章节与小节书签、三幅图，以及教学样例和真实错误案例。PDF 已嵌入中文字体，可独立阅读和分享。

## 从哪里开始

- [详细说明 PDF](DisasterTrace_Detailed_Progress_CN.pdf)：适合完整阅读。
- [同内容 Markdown](DisasterTrace_Detailed_Progress_CN.md)：适合编辑，或交给 ChatGPT 精简。
- [全部汇报版本索引](../PDF_INDEX.md)：保留 P6 完成版与 P6 + P7 更新版演示 PDF。

如果时间有限，先读第 4 章的逐轮教学样例和第 5 章的三种方法，再读第 7–8 章的实测结果与真实错误，最后读第 14–15 章的完成情况与后续计划。遇到 episode、轨迹、Gold 或 scorer 等术语时，可返回第 2 章查阅。

希望从头理解时，按第 1–5 章（任务原理）、第 6–9 章（P6 实测）、第 10–12 章（P7 原生任务）、第 13–16 章（工程状态、限制与后续路线）的顺序阅读。第 17 章提供证据入口。

## 本文的进展边界

证据核对日期为 2026-09-08，内容固定于 P6 已验收模型结果和 P7 已验收离线任务。本文是这个里程碑的说明，不会随着其他后台任务自动更新。

| 阶段 | 已完成 | 数字的含义 |
| --- | --- | --- |
| P6 | Qwen3-8B 真实模型实测与独立结果核验 | 2,160 条回答，1,861 条完整正确，约 86.2% |
| P7 离线 | 官方预报原文任务、独立求解、评分和九种程序对照 | 46 个目标、257 个查询；模型调用为 0 |
| 后续原生实测 | 本文所述里程碑中尚未执行 | 1,542 是三种方法、两次重复的计划回答机会 |

“完整正确率”包含数值、状态、目标、单位、当前来源与定位等联合要求，不是实际天气预测准确率。P6 的 2,160 条回答只涉及三个独立风暴来源；P7 的原生来源只有两个风暴。
