This companion is fixed before P11/P12 model scores or any P13 generations are
read. Known P9 common-contract failures and the archived DeepSeek no-system-prompt
recommendation motivate the P13 study. Applying the same role intervention to
Qwen tests whether effects are model-specific under the retained protocol;it
does not claim Qwen's model card requires this alternative.

default-JSON-spacing execution on the P10 six-storm development task. Preserve

workers,whole-target ownership,seeds,public data,Gold,scorer,SCHEMA,contract bytes,
default JSON spacing,native qwen3 reasoning parser,BF16,TP1,batch4,context32768,
output8192,temp0.6,top_p0.95,top_k20 and the whole-worker stop policy.

original system content,then two newline characters,then the original user
content. Keep both logical messages and the actual rendered message/hash,prompt
and prompt token IDs. No new examples,hints,correct values,source IDs,repair,
unit normalization or new instruction text is allowed. The live engine consumes
the bound actual prompt token IDs. Program diagnostics consume the unchanged
logical task and never enter model histories. P14 uses only its own generations.

Use a distinct qwen_role_live namespace,origins,execution identities and one-use
claims. Never modify P7/P9/P11/P12/P13 scientific bytes or share model-generated
histories between studies. Core and actual installed-backend tests must verify

report reconstruction,isolated CPU review and a fresh no-generation H100 preflight.

and then checks capacity for one H100. This ordering prevents competing unfenced
phase submissions. Live dispatch waits for the two P12 Qwen jobs and this
preflight to release,with capacity for two more H100s. It may overlap P13's two
DeepSeek jobs. Count all owned active and pending allocations,never more than4.

Report full-denominator coverage,strict all-field scores,units,time keys,values,
citations,format/length failures,tokens,H100 time and single-repeat whole-target

stop a complete worker;bounded formatting does not bound arbitrary string length
or guarantee a completed final answer. Preserve every such failure and unattempted
slot. This companion is not a repair,retry or replacement of a historical run.
