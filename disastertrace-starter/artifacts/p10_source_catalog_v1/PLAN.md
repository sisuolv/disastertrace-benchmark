first native task validation. This CPU-only source step uses the remaining
autonomous window and preserves every P7/P8/P9 task and model claim.

Dorian AL052019, Isaias AL092020, Henri AL082021, Fiona AL072022,
Lee AL132023 and Helene AL092024. These are a declared, curated year-spread
development cohort, not a probability sample of hurricanes or extreme weather.

before acquisition, source parsing or any model score for this cohort.

advisory or storm to improve coverage.

headers before admission. Preserve all failures and disagreements. Record issue
time, explicit center time, row valid time and retrieval time separately; actual
historical public availability remains unknown. No manual per-item annotation,
LLM judge or model-generated reference is involved.

This catalogue has no model dispatch path, no GPU allocation and no change to an
existing denominator. Report exact storms, products, future target keys, adjacent
