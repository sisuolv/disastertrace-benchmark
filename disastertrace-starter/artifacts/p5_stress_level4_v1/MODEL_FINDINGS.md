## 4. 如何理解这次比较

三个因素都保留相同的 36 个基础 episode 映射，逐一核对 180 个 checkpoint 的
值、状态、当前引用和动作 Gold。模型、基础采样、结构 grammar 和父版本源码
保持一致；每个方法的 116 个指标分母及全部 checkpoint 机会均通过对照。

公开证据的变化来自预先固定的压力变换。每条实际请求的证据和 system prompt
均与对应冻结任务核对；部分早期 checkpoint 尚未收到新增记录，因此输入可以
相同。全部 1,620 个新 slot 使用其新身份派生的随机种子。模型回答变化也会改变
后续合法历史载体。P4 使用 MIG，P5 使用完整 H100，这一硬件变化同样保留在记录中。

因此，本轮给出的是描述性的开发实验结果。108 个因素变体来自同样三个来源组，
不能当成 108 个独立天气事件；一次采样也不足以支持广泛显著性结论。所有方法
仍可看到累计公开证据，不能据此推断内部记忆能力或天气预报精度。
