# 本阶段之后的执行建议

本轮交付的边界是：平衡开发集、真实本地第二模型实验、完整自动审计，以及
未调用模型的难度候选。最终数字以 `FINDINGS.md` 与独立报告为准。后续仍保留
不新增逐题人工标注/复核、不用 LLM judge 的原则。

## 1. 先明确格式错误在 benchmark 中扮演什么角色

自由 JSON 输出是当前协议的一部分，应继续原样保留，作为“能否遵守接口”的
实测结果。JSON 不合法时，主评分保留其全部失败机会，不能按修复后的答案计分。
与此同时，大量语法失败会遮住对状态修订、作用域选择和引用更新能力的判断。

推荐准备一条独立的受约束结构输出轨道，和现有自由输出轨道分表呈现：

1. 固定相同 episode、公开证据、三种方法、自动 Gold 和主语义评分。
2. 用统一 JSON Schema / grammar 只约束容器结构、字段类型和合法字面量。
   不根据 Gold 设置数值；不把当前记录 ID 或正确行号枚举进 grammar；也不把
   风速与 action 的对应关系编译成会替模型完成决策的约束。
3. 检查每个模型/后端实际支持的约束程度，并提前确定如何比较不支持该功能的
   provider。不能把一方的强 schema 解码和另一方的普通 JSON 模式当作相同设置。
4. 先完成全量离线 schema/自动 Gold 兼容验证、错误保留和载体隔离测试，再
   固定新的执行身份与完整矩阵。已有自由输出答案不作为新轨道的历史或替代答案。

如果研究目标确实包含“自由文本下可靠遵守 JSON 接口”，现有失败本身就是
结果；不应为了漂亮分数不断修改提示词。结构轨道服务于另一个明确的测量问题。
本轮没有执行该新轨道，也不把它当作现成可用功能。

## 2. 完成同一平衡版本上的模型对照

本轮旧任务重叠子集对照仅为描述性辅助；完整 540 版本仍只有一个已运行模型。
下一轮应让 DeepSeek 或另一个明确选定的模型也使用同一平衡数据、输出协议、
方法载体和固定分母，分别记录其 tokenizer、reasoning、采样与实际使用量。

远程 provider 路径的 270 固定调度、可靠性单元计数和预算保护需要版本化适配
到 540。不能把旧执行文件的数字直接替换，或绕过旧采集器的身份/来源检查。
若要使用付费 API，先读取当时价格和接口能力并形成单独限额；历史已消耗预算
不重新计入可用额度。相同 token cap 也不等于不同模型使用相同推理计算量。

若计划比较方法优劣，应至少增加预先固定的独立采样重复，并报告各来源组内
的配对结果。三个来源组仍然不足以支持稳定的广域显著性结论；不要把连续
checkpoint 和匹配分支当作独立事件进行普通二项区间或大样本显著性检验。

## 3. 难度候选先校准，再推理

`stress_offline/` 已有 216 个自动验证候选：修订链、无关作用域、旧记录重放
三个因素，各 4/16 两个水平，一次只改变一个因素。1,080 个 checkpoint 的原始
Gold 不变，3,240 次公开 oracle 比较通过。

下一步先对每一难度单元测量实际 tokenizer 输入长度、可用输出预算和完整
轨迹载体增长；超上下文的候选不能被静默截断。分开报告三种因素及有效强度，
尤其是没有 PATCH 可扩展的 control。需要研究交错改值或更多决策翻转时，另立
自动生成与对照规范，不根据本轮哪道题答错决定保留哪些变体。

该候选集合不是新增 216 场独立天气事件。其基础来源仍是三个开发风暴，修订
过程仍是研究构造。复杂度提高不自动等于真实天气知识覆盖提高。

## 4. 再进入真正的泛化评测

在模型接口、生成分布、所有模板/参数、评分和重复数冻结后，才进入七个保留
风暴。要分别定义三个目标：新来源事件、新数值/种子、未参与开发的操作组合。
其中任何一个都不能替代另外两个。

长期应把受控记录修订与真实极端天气文本任务分成不同轨道。现有 NHC 来源
主要覆盖热带气旋，不能代表高温、寒潮、暴雨洪水等全部极端天气。扩展新灾种
时，优先寻找带结构化观测、告警更新链和明确生效时间的公开数据；只有能够
建立可执行、可追溯的标签规则时，才纳入无需逐题人审的主评测。

## 5. 工程维护

保留所有 raw 输出、版本化数据和停止记录。独立验证报告可在无 GPU、无权重、
无 API key 的环境运行。下一次采集继续使用全新身份/目录，不重启本轮已消耗
的 launch。进一步的恢复工具应覆盖部分文件写入、进程被强制终止等情况；当前
严格审计遇到损坏文件会拒绝给出成绩，不自动猜测或覆盖内容。

优先级建议：输出轨道的测量定义与离线适配 → 相同平衡版本的多模型/重复采样
→ 难度因素与上下文预算校准 → 留出事件 → 新灾种扩展。当前阶段不发布最终榜单。
