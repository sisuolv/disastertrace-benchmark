# 后续难度版本的离线准备

本文件及生成规则在本轮 Qwen 模型输出产生前确定。当前只做自动验证，没有为
难度版本调用模型，也没有根据模型错误选择题目。实际 540 条平衡实验不受影响。

| 独立因素 | 两个水平 | 自动验收要求 |
| --- | --- | --- |
| 修订链长度 | 每条既有 PATCH 前插入 4 / 16 条中间修订 | 显式父版本链合法；每个 checkpoint 的值、状态、最终引用和 action 与原题一致 |
| 无关作用域 | 增加 4 / 16 条其他实体或其他有效窗口记录 | 不与既有根事实重合，不影响目标 Gold |
| 较晚旧版本重放 | 最后一个 checkpoint 再收到 4 / 16 次初始旧记录 | 不改变当前权威版本；不能用最后到达的文档替代逐事实修订规则 |

三个因素分别应用于全部 36 个平衡 episode，两个水平各一套，总计 216 个
候选 episode。逐 checkpoint 的 1,080 次原题/变体 Gold 比较，以及三种方法
合计 3,240 次独立公开解析比较，都必须通过。有效新增记录和 delivery 数逐题保存。

修订链变体仅扩展原题已存在的 PATCH，并使用与终点相同的数值；它首先检验
版本追踪和证据量的影响。U2 control 中没有 PATCH 的题目仍是零强度对照，不能
把这些题目当作已有同等长度修订链。后续若研究多个事实的交错改值，应单独设计。

无关窗口从目标窗口后的第 10 天起偏移，避开原题已有的次日窗口对照。离线
验收最初发现与该次日窗口冲突、形成同键双根，现有 schema 正确拒绝了这种
构造；回归测试覆盖所有原题分支后才修正生成规则。失败和修复记录均保留。

这些变体保持原有语义和 checkpoint Gold，但增加了证据长度。它们还没有完成
模型 tokenizer 下的上下文/输出预算校准，因此是可审阅的离线候选，不能直接
作为已经冻结可调用的模型矩阵。未来模型推理需要独立数据/执行身份和明确数量。
