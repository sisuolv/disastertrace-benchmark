# Independent audit materials

This directory contains independent review material for the v21 benchmark release.

- [Independent review (Chinese)](INDEPENDENT_REVIEW_V21_20260926_CN.md): current code, evidence, protocol risks, scientific interpretation, and next-step priorities.
- [ChatGPT review prompt](../CHATGPT_REVIEW_PROMPT_V21_20260926.md): prompt for a second independent analysis using the checked-in code and evidence.

The review deliberately separates four claims: implementation correctness, execution success, method validity, and research novelty/value. The current evidence supports only scoped engineering/protocol claims and a conditional synthetic mechanism hypothesis; it does not establish weather value, provider/LLM benefit, generalization, or novelty.
