# v21 release handoff (2026-09-25)

This release packages the repaired v18/v19 implementation, the v21 Natural
selector code, and the evidence from execution `v21_execution_20260925_04`.
The release is intended for code review and reproducible follow-up work. It
does not contain raw weather archives, quarantine/holdout material, or model
credentials.

## What is included

- `src/disastertrace/monitoring_v1/*v21.py` implements the typed Natural
  selector, content-dependent policy, delivery intervention, synthetic score,
  and repair/sham controller.
- `scripts/run_v21_*.py` contains the synthetic diagnostics and the bounded
  real-development source bridge, ASOS outcome binding, and deterministic
  evaluator.
- `tests/test_v21*.py` and the v18/v19 regression tests cover the contracts
  used by the release.
- [`artifacts/v21_execution_20260925_04/`](../artifacts/v21_execution_20260925_04/)
  contains the frozen execution handoff, manifests, logs, all per-cell GPU
  outputs, and the six completed tide-job receipts.
- [`docs/plans/PLAN_V21_AUDIT_20260925_CN.md`](plans/PLAN_V21_AUDIT_20260925_CN.md)
  records the latest plan audit used to choose the execution scope.

## Evidence boundary and current result

The bounded development run contains 24 TAF episodes and 72 checkpoints.
Visibility is normalized to metres and TEMPO/PROB semantics are retained. The
evaluator-only ASOS binding covers 24/24 targets from KDEN, KJFK, KORD, and KSFO
in January/March 2025. It has 22 negative and 2 positive outcomes, so it is a
small diagnostic rather than a general weather claim. The deterministic source
arms all have mean Brier score `0.1104167` and are tied across the 72 cells;
the active policy therefore has no independent real-dev advantage in this run.

The three cost-matched synthetic GPU replicas use the same two-query budget and
common denominator for every method. Across 1,152 cells, active minus the best
non-active arm is `-0.011311` with 816 wins, while active minus the fixed prior
is `-0.043942`. This supports a conditional mechanism hypothesis about
content-dependent follow-up selection under finite cost. It is synthetic
mechanism evidence, not an empirical provider or novelty result.

No provider/model call was made in this execution because no credential was
available. No holdout, quarantine, or protected February window was read, and
the actor never received evaluator outcomes. These boundaries are recorded in
`TEST_STATUS_V4.json` and `HANDOFF_REPORT_V4.md`.

## Reproduce

See [`artifacts/v21_execution_20260925_04/REPRODUCE.md`](../artifacts/v21_execution_20260925_04/REPRODUCE.md)
for the exact local test, source-bridge, deterministic-score, and GPU commands.
The commands that require weather data take an external `--data-root`; that
data is deliberately not part of this repository.

```bash
cd disastertrace-starter
.venv/bin/python -m pytest \
  tests/test_v17*.py tests/test_v18*.py tests/test_v19*.py tests/test_v21*.py -q
.venv/bin/python -m compileall -q src scripts tests
```

The repository contains an offline GitHub Actions template under
`docs/ci/`; this handoff reports local checks only and does not claim that
hosted CI has run.
