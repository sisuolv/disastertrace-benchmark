# DisasterTrace 整体灾种与数据蓝图

**版本：2026-09-11。文档身份：总体设计，不是下一周计划、采集完成报告或实验结果。**

## 一、整体决定

最终范围固定为16个灾害家族；洪水、气旋或温度只是不同时期可以用于验证的模块，不等于整个benchmark。每个家族单独定义未来目标、基础预报、可查询证据与结果参考，统一共享E/F协议、时间、预算、来源与分组机制。

E轨检验证据是否充分、版本/时间/覆盖与引用是否正确。F轨检验对固定未来风险的预测，并独立报告在公开准备截止与成本规则下的决定价值。产品事实证书不为未来概率提供逐题唯一正确答案。

该 taxonomy 是工程任务家族，不是声称16类在物理机制上相互排斥的国际标准。复合事件多标签但共享物理事件组。地震、火山、海啸不纳入极端天气主范围；降雨滑坡等保留为另行定义的次生灾害扩展。

沿用用户两份文件的16类范围及无新增逐题人工复核/LLM judge约束。以下为总体产品选择建议；文档核验与附件报告的已有样例不等于全量数据下载和可结算任务完成。

## 二、关键来源更正

NOAA于2026-06-23公告：旧ISD/Global Hourly在2025-08-24之后不再更新，鼓励使用GHCNh。总体设计将GHCNh作为新增站点资料主入口，旧ISD用于固定历史版本复现。GHCNh档案同样不能自动证明原始观测当时在线可得；实时轨需保存METAR/SYNOP等实际可核验端点回执，或按可取得时间使用GHCNh。见[S04][S33]。

## 三、16个灾害家族总表

| ID | 家族 | 拟议未来目标 | 结果身份 |
|---|---|---|---|
| H01 | 热带气旋 | 给定已监测气旋，在固定未来T的最大持续风是否超过阈值，或位置误差是多少。 | P |
| H02 | 温带风暴／非对流大风 | 固定站点/区域未来时窗中规定采样的持续风或阵风是否越阈。 | O / R |
| H03 | 雷暴大风／下击暴流 | 固定区域未来时窗是否出现达到阈值的对流阵风测量，或登记的雷暴大风报告。 | O / R |
| H04 | 龙卷风 | 固定监测区域未来窗口是否出现经规定报告/调查体系确认的龙卷事件。 | R |
| H05 | 冰雹 | 未来区域出现直径越阈的冰雹报告；另设未来雷达冰雹代理产品越阈目标。 | R / P |
| H06 | 强雷电 | 固定面积和未来窗口内，GLM有效覆盖下的flash密度是否越阈。 | P |
| H07 | 极端降水 | 固定站点/区域未来1/3/6/24小时累计降水是否越阈；站点与格点产品结果分开。 | O / P |
| H08 | 洪水／山洪／城市内涝 | 未来站点水位或流量越阈；城市积水与山洪使用独立结果规则，不共用一个模糊洪水标签。 | O / R / P |
| H09 | 风暴潮／沿岸淹没 | 固定沿海测站未来总水位是否越过同基准阈值；淹没范围另设任务。 | O |
| H10 | 热浪／极端高温 | 未来固定日期/小时窗达到温度阈值，或满足地区气候相对阈值和持续规则。 | O |
| H11 | 寒潮／低温／霜冻 | 未来低温越阈或温降过程满足规则；空气低温与实际霜冻损害分开。 | O |
| H12 | 暴雪／积雪／冰冻降水 | 未来降雪/积雪阈值或冻雨现象；不同冬季子任务独立定义。 | O / P / R |
| H13 | 干旱／闪旱 | 未来指定周的USDM等级/覆盖越阈；闪旱需另设快速变化、持续性和恢复规则。 | P |
| H14 | 沙尘暴 | 未来站点窗口是否有规定沙尘暴现象及低能见度；CAMS沙尘产品越阈另列。 | O |
| H15 | 浓雾／极端低能见度 | 固定站点未来窗口能见度低于阈值，且浓雾任务满足规定现象与持续性。 | O |
| H16 | 天气相关野火／火险 | 未来火险指数是否越阈；或已知火场下一次合格观测中活动火产品面积/像素是否扩大。 | P |

O：质量合格观测；P：明确产品/分析/专家标签；R：报告/调查系统定义的发生。三者分轨，不能统一称为无偏物理真值。

## 四、逐灾种的数据合同

下面提前量是建议的任务档位，不是已验证产品全支持，也不是官方业务规范。实际产品有效窗与监测目标不匹配时，资料只能作上下文，不能伪装成同目标概率基线。

### H01 热带气旋

**子类：** 已被监测气旋未来强度；未来位置/轨迹；与强度独立任务；登陆等扩展须独立定义。

**未来目标：** 给定已监测气旋，在固定未来T的最大持续风是否超过阈值，或位置误差是多少。

**建议时间尺度：** 6–72小时；建议任务范围，不是统一产品保证。

| 数据角色 | 选定来源/规则 |
|---|---|
| 基础预报 | NHC Forecast/Advisory 与归档 [S06] |
| 可主动读取的证据 | NHC Forecast/Advisory 与归档 [S06]；NOAA GOES ABI / GLM [S12]；NOAA GFS [S01]；NOAA GEFS [S02] |
| 未来结果/参考 | NHC HURDAT2 / data [S07]；NCEI IBTrACS [S08] |
| 现成benchmark复用 | 既有NHC任务；ExtremeWeatherBench；WeatherQA/CyPortQA仅合格上游资料索引 |
| 地域边界 | NHC覆盖海盆；跨海盆扩展需对应官方预报，不以IBTrACS全球覆盖冒充预报全球覆盖。 |

**处理规则：**

1. 按storm_id+target_valid_time连接预报版本和结算；保存原机构与风速平均时间。
2. 同目标跨版本是修订；T改变是另一个目标。
3. HURDAT2/IBTrACS为事后分析；风圈不直接等于地点实测风；不同海盆官方预报另接。

**F轨准入：** 有匹配未来最佳路径记录及输入时间政策；不得按未来强度/登陆倒选所有样本。

### H02 温带风暴／非对流大风

**子类：** 非对流持续大风；非对流阵风；温带风暴身份可靠时的分层。

**未来目标：** 固定站点/区域未来时窗中规定采样的持续风或阵风是否越阈。

**建议时间尺度：** 6–48小时。

| 数据角色 | 选定来源/规则 |
|---|---|
| 基础预报 | NOAA GFS [S01]；NOAA GEFS [S02]；NOAA HRRR [S03] |
| 可主动读取的证据 | NCEI GHCNh [S04]；NOAA GOES ABI / GLM [S12]；NOAA GFS [S01]；NOAA GEFS [S02] |
| 未来结果/参考 | NCEI GHCNh [S04]；NCEI Storm Events [S13] |
| 现成benchmark复用 | EWB相关事件索引；无强制现成专用QA集 |
| 地域边界 | 全球合格站点；HRRR只用于其区域覆盖。 |

**处理规则：**

1. 持续风与阵风分别定义；保持高度、平均时间和单位。
2. 风速越阈与风暴成因分开；无法自动可靠归因的不标温带风暴。
3. 用站点QC及覆盖确认负例，报告作为独立附加结果。

**F轨准入：** 预报与站点的风变量一致；成因不明可保留通用大风任务但不能伪造子类。

### H03 雷暴大风／下击暴流

**子类：** 对流直线大风；有明确调查证据的下击暴流。

**未来目标：** 固定区域未来时窗是否出现达到阈值的对流阵风测量，或登记的雷暴大风报告。

**建议时间尺度：** 约1–6小时。

| 数据角色 | 选定来源/规则 |
|---|---|
| 基础预报 | SPC Outlook / Mesoscale Discussion [S09]；NOAA HRRR [S03] |
| 可主动读取的证据 | NOAA NEXRAD [S10]；NOAA MRMS [S11]；NOAA GOES ABI / GLM [S12]；NCEI GHCNh [S04] |
| 未来结果/参考 | NCEI GHCNh [S04]；NCEI Storm Events [S13] |
| 现成benchmark复用 | SEVIR原生资料；EWB强对流案例；WeatherQA合格上游图文 |
| 地域边界 | 以具有雷达、站点与报告交集的地区为主，当前拟定资料偏美国。 |

**处理规则：**

1. SPC风险区域/时间窗与查询目标不一致时只作上下文，不称同目标概率基线。
2. 雷达/VIL不自动证明地面阵风；下击暴流无可靠调查依据不细分。
3. 测量值、估计风速和报告计数保持不同身份。

**F轨准入：** 物理风速O轨和报告R轨单独准入；不得以无报告当物理无事件。

### H04 龙卷风

**子类：** 未来登记龙卷事件；雷达探测/追踪作为独立E诊断。

**未来目标：** 固定监测区域未来窗口是否出现经规定报告/调查体系确认的龙卷事件。

**建议时间尺度：** 30分钟–3小时为建议短临档位；业务outlook支持另列。

| 数据角色 | 选定来源/规则 |
|---|---|
| 基础预报 | SPC Outlook / Mesoscale Discussion [S09] |
| 可主动读取的证据 | NOAA NEXRAD [S10]；NOAA GOES ABI / GLM [S12]；TorNet [S27]；NOAA HRRR [S03] |
| 未来结果/参考 | NCEI Storm Events [S13]；TorNet [S27] |
| 现成benchmark复用 | TorNet修订标签版；EWB强对流事件索引 |
| 地域边界 | 官方报告/调查与雷达覆盖交集，明确地域和检测偏差。 |

**处理规则：**

1. TorNet按每帧时刻和已登记起止时间截断；灾中雷达不能用于灾前预测输入。
2. 确认预先监测区域；不能用未来路径反向裁剪输入并泄漏目标。
3. NUL/无报告只可按数据集报告定义为负例，不能宣称所有物理龙卷均被排除。

**F轨准入：** 未来报告源、终止版本、报告时空支持可确认；概率评分命名为报告事件预测。

### H05 冰雹

**子类：** 地面冰雹直径阈值；雷达冰雹代理阈值。

**未来目标：** 未来区域出现直径越阈的冰雹报告；另设未来雷达冰雹代理产品越阈目标。

**建议时间尺度：** 1–6小时。

| 数据角色 | 选定来源/规则 |
|---|---|
| 基础预报 | SPC Outlook / Mesoscale Discussion [S09]；NOAA HRRR [S03] |
| 可主动读取的证据 | NOAA NEXRAD [S10]；NOAA MRMS [S11]；NOAA GOES ABI / GLM [S12] |
| 未来结果/参考 | NCEI Storm Events [S13]；NOAA MRMS [S11] |
| 现成benchmark复用 | EWB强对流索引；SEVIR只作相关雷达输入 |
| 地域边界 | 有地面报告和雷达产品交集的区域；全球转移单独验证。 |

**处理规则：**

1. 地面直径与MESH等雷达估计分表，不能混为Gold。
2. 毫米/厘米/英寸统一但保留原始值及估计/测量来源。
3. 未来产品参考不可由早期预报数值生成。

**F轨准入：** 报告和代理产品两个结果轨具有各自负例规则与覆盖。

### H06 强雷电

**子类：** 区域总闪电密度越阈；相对独立基准的极端闪电活动。

**未来目标：** 固定面积和未来窗口内，GLM有效覆盖下的flash密度是否越阈。

**建议时间尺度：** 5–60分钟。

| 数据角色 | 选定来源/规则 |
|---|---|
| 基础预报 | 不假定存在同目标官方概率；用公开的持续性/外推及开发冻结基线 |
| 可主动读取的证据 | NOAA GOES ABI / GLM [S12]；SEVIR [S28]；NOAA NEXRAD [S10]；NOAA HRRR [S03] |
| 未来结果/参考 | NOAA GOES ABI / GLM [S12] |
| 现成benchmark复用 | SEVIR配对资料；采用持续性/外推/开发校准的同目标基线 |
| 地域边界 | GLM合格覆盖范围；其他闪电网需单独定义传感器与标注。 |

**处理规则：**

1. flash、group、event按产品层级解析与关联，主密度不把event数量当flash数。
2. 跨文件边界去重，固定有效空间和时间分母及质量规则。
3. 总闪电不等于云地闪电或人员伤害；极端阈值来自独立基准期。

**F轨准入：** 未来完整有效产品；没有官方同目标概率时如实使用专业外推/持久性基线。

### H07 极端降水

**子类：** 短历时强降水；多小时/日累计极端。

**未来目标：** 固定站点/区域未来1/3/6/24小时累计降水是否越阈；站点与格点产品结果分开。

**建议时间尺度：** 1–48小时预报；目标累计窗独立记录。

| 数据角色 | 选定来源/规则 |
|---|---|
| 基础预报 | NOAA GFS [S01]；NOAA GEFS [S02]；NOAA HRRR [S03]；WPC precipitation / winter products [S19] |
| 可主动读取的证据 | NCEI GHCNh [S04]；NCEI GHCN-Daily [S05]；NOAA NEXRAD [S10]；NOAA MRMS [S11]；NOAA GOES ABI / GLM [S12] |
| 未来结果/参考 | NCEI GHCNh [S04]；NCEI GHCN-Daily [S05]；NOAA MRMS [S11] |
| 现成benchmark复用 | EWB降水事件；SEVIR；其他降水集仅保留清楚原始角色 |
| 地域边界 | 全球站点/全球预报；高频雷达子集按覆盖区域报告。 |

**处理规则：**

1. 降水率积分、累积差分与预报周期重置按元数据处理。
2. 站点日与UTC小时窗不强行对齐，雨雪相态与水当量保留。
3. MRMS可能融合站点，不能当完全独立第二观测；缺站不自动为0。

**F轨准入：** 同累计支持的预报与观测，完整QC和正常窗口。

### H08 洪水／山洪／城市内涝

**子类：** 河流水位越阈；极端流量越阈；山洪报告；有真实积水资料的城市内涝；遥感水体/洪水范围E诊断。

**未来目标：** 未来站点水位或流量越阈；城市积水与山洪使用独立结果规则，不共用一个模糊洪水标签。

**建议时间尺度：** 河流6–48小时；山洪/内涝短临1–6小时为拟议档位。

| 数据角色 | 选定来源/规则 |
|---|---|
| 基础预报 | NOAA NWPS / HEFS [S14] |
| 可主动读取的证据 | USGS Water Data APIs [S15]；USGS NIMS [S16]；NOAA GFS [S01]；NOAA GEFS [S02]；NOAA MRMS [S11]；GEOID-Flood [S29]；WorldFloods / ml4floods [S30] |
| 未来结果/参考 | USGS Water Data APIs [S15]；NCEI Storm Events [S13]；GEOID-Flood [S29]；WorldFloods / ml4floods [S30] |
| 现成benchmark复用 | GEOID-Flood、WorldFloods/CEMS做合格空间标签诊断；不保证同事件与站点配对 |
| 地域边界 | 美国业务水文可核配对子集；遥感跨国诊断独立，不假定全球业务预报。 |

**处理规则：**

1. 先官方站点映射，再核变量/单位/垂直基准和时间支持；流量不直接与水位比较。
2. HEFS完整成员值与未来同站观测连接；起报、创建、可用、捕获不同。
3. 未来结果Provisional/Approved单独冻结；NIMS无标定不生成精确水位视觉Gold。
4. 遥感Gold及派生validity不得作为早期输入；永久水与新增淹没分开。

**F轨准入：** 预报值、站点、变量、阈值、未来结果与时钟全部配对；城市内涝缺参考时保留空缺而非用河洪代填。

### H09 风暴潮／沿岸淹没

**子类：** 沿海总水位越阈；严格定义的非潮残差；有合格空间标签的沿岸淹没。

**未来目标：** 固定沿海测站未来总水位是否越过同基准阈值；淹没范围另设任务。

**建议时间尺度：** 6–48小时。

| 数据角色 | 选定来源/规则 |
|---|---|
| 基础预报 | NOAA NOS Operational Forecast Systems [S18] |
| 可主动读取的证据 | NOAA CO-OPS [S17]；NHC Forecast/Advisory 与归档 [S06]；NOAA GFS [S01]；NOAA GEFS [S02] |
| 未来结果/参考 | NOAA CO-OPS [S17] |
| 现成benchmark复用 | 既有CO-OPS配对；气旋/沿海事件索引 |
| 地域边界 | 有OFS和CO-OPS交集的沿岸区域；其他国家服务作为独立适配。 |

**处理规则：**

1. 匹配区域OFS业务预报与CO-OPS站点、单位、datum。
2. 天文潮预测是基础分量/基线，不是总水位风暴预报。
3. 观测减预测潮是非潮残差，不自动证明纯风暴潮；测站越阈不是空间淹没。

**F轨准入：** 未来总水位参考可结算；因果/淹没细类只有其自身标签成立时发布。

### H10 热浪／极端高温

**子类：** 固定窗口高温越阈；满足预设持续条件的热浪。

**未来目标：** 未来固定日期/小时窗达到温度阈值，或满足地区气候相对阈值和持续规则。

**建议时间尺度：** 1–7天。

| 数据角色 | 选定来源/规则 |
|---|---|
| 基础预报 | NOAA GFS [S01]；NOAA GEFS [S02] |
| 可主动读取的证据 | NCEI GHCNh [S04]；NCEI GHCN-Daily [S05]；NOAA GOES ABI / GLM [S12] |
| 未来结果/参考 | NCEI GHCNh [S04]；NCEI GHCN-Daily [S05] |
| 现成benchmark复用 | ExtremeWeatherBench热浪案例；ExEBench仅合格来源/事件定位 |
| 地域边界 | 全球合格站点，按气候区/季节/产品版本分层。 |

**处理规则：**

1. 2m气温不与地表温度互换；网格至站点映射、距离和高程差保留。
2. 阈值和基准期在测试前冻结；单次固定温度越阈不自动称热浪。
3. 用完整目标期的当地日支持/采样规则判持续，不能未来填补输入。

**F轨准入：** 业务预报与观测高度/支持一致，足够独立正常/近阈/高温窗口。

## 五、共用数据层，而不是16套独立工程

| 层 | 主要内容 | 处理原则 |
|---|---|---|
| 预报 | GFS/GEFS、HRRR、NHC、SPC/WPC、HEFS/NWPS、OFS、CAMS、CPC、EFFIS | 冻结每次产品版本、起报/创建/有效时间与变量；事后回算不冒充业务预报 |
| 观测 | GHCNh/GHCNd、USGS、CO-OPS、NEXRAD/GOES | QC、原始采样和空间支持保留；历史当时版与后续确认版不互相覆盖 |
| 标签/分析 | HURDAT2/IBTrACS、USDM、Storm Events、洪水/野火已有标签 | O/P/R分开；专家来源披露；事件报告不保证观测完备 |
| 资产表示 | 原生影像、图表、地图、摘要及工具输出 | 所有派生表示绑定同一规范产品；标签衍生字段不进入无权限公开输入 |
| 交互样本 | 固定目标、可用目录、有序交付、请求回执和预测提交 | 查询时间不等于返回时间；未来/未读/私有资料不可见 |

## 六、统一处理流水线

原始资产 → 无损捕获与版本注册 → 解码/单位/QC → 时空及站点连接 → 固定目标与自动参考 → 分组切分 → 公开证据与私有结果隔离 → 可回放样本。

推荐保留raw原格式；标量/索引使用Parquet；网格保持NetCDF/Zarr/GeoTIFF等适当科学格式；图像保留原JPEG/PNG和单列渲染资产；任务与manifest使用JSON/JSONL。不能为了统一多模态而只保留截图。

每个产品最少保存：source_id、product_id、version、parent_ids、sha256、variable、unit、vertical_reference、spatial_support、observation/valid/issue/create/capture/availability时间、QC、nodata、license、original_split、exposure_status。

每个目标最少保存：hazard/subtype、entity/AOI、固定未来窗、变量/单位/统计/采样、阈值和基准期、截止、允许来源、结果身份O/P/R及解析器版本。

### 时间与结果的四条边界

1. 不将issue_time、观测有效时间、下载时间互相替换。严格历史as-of、受控回放、前瞻first-seen分开报告。
2. 输入只能使用当时可取得的版本；未来QC订正另存Outcome版本。未结算窗口保留，不自动变负例。
3. 决策截止在看见结果前定义；不得按事后灾害首次发生时刻倒推deadline。
4. 同一场事件的信息交付分支可有不同EvidenceReference，但共用同一OutcomeReference。

### 不同的失败/不确定状态

| 状态 | 意义 |
|---|---|
| rejected / quarantined | 文件、站点、变量、权利或科学语义不能成立；不生成正式任务 |
| E unknown | 数据本身合格，但当前证据不足以支持产品事实 |
| F unresolvable | 未来观测/标签的质量或覆盖不足，不能结算 |
| Y=0 | 在声明观测或报告定义下可确认的负例；必须保留其结果身份 |

## 七、总体抽样、地域和数量口径

监测集合在未知结果前固定站点/区域、日期、阈值和机会窗，保留正常、近失和真实极端。机制诊断可富集困难修订、缺测和异常交付，但与发生率集合分开。

地区设计采用全球共享预报/站点背景与区域高密度传感器模块。当前可选核心明显偏美国，欧洲CAMS/EFFIS和全球站点/气旋资料提供互补，不宣称16灾种都全球覆盖。每个数据卡同时列国家/气候区、年份、机构、版本和实际结果覆盖。

不统一规定全部来源同一开始年份。业务产品升级、雷达/卫星任务和档案覆盖不同，应选可追溯重叠期，并把不同技术版本作为分层。对16类可以预设机制覆盖目标，但最终独立事件数和窗口数以实际来源与统计功效确定，不用重复问法凑配额。

同时发布source family、product revision、physical event group、monitoring window、frame/tile、task、checkpoint和run数量；其中后四项不替代独立事件组。

## 八、与当前idea对应的研究用途

| 研究机制 | 最直接的数据家族 |
|---|---|
| 同一未来目标的自然预报修订 | 气旋、大风、温度、业务水文、海岸水位 |
| 覆盖不足与获取下一份证据 | 洪水遥感、强对流、闪电、野火和站点缺测 |
| 新观测与旧事实重呈现 | 预报地图/数值/文本、同源转述、派生产品 |
| 不同信息节奏与截止要求 | 分钟级强对流、小时级水文/降水、日级温度、周级干旱 |
| 相对强预报基线的增量 | 有同目标业务基线和未来结果的全部合格F子集 |

不存在同目标官方概率时，不把不同目标outlook硬套为基线；使用明确的专业外推、持续性或开发冻结的校准/统计基线，并保留权限和成本。范围广是外推验证的条件，不是单独的novelty。

## 九、最终发布形态

最终交付应包含16个灾种数据卡、细类覆盖矩阵、固定版本下载/重建清单、规范产品与来源图、独立事件/监测机会索引、E/F任务数据和公开输入、私有结果解析器、强基线、以及按灾种/结果身份/时间有效性/预算/提前量分层的结果。

预测质量、截止前研究决定价值、证据合法性分别报告。不把观测结果、产品等级、报告事件直接压成一个模糊的“16灾种物理预警准确率”。实时影子运行不发布公众预警或改变真实设施。

总体16类纳入决定可以现在冻结；具体产品版本、站点/事件交集和细类可结算样本由真实数据决定。存在目录、成功解码和正式预警任务是三个独立状态，发布覆盖表必须显示差别。
