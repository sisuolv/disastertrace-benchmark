# ActiveWarning minimum loop and research review

Start with [the Chinese review brief](REVIEW_FOR_CHATGPT_PRO_CN.md).

The real-data LLM minimum loop is complete: 84 development targets, 7,056 program
trajectories, two Qwen3-8B matrices with 1,120 actual replies. The second matrix
has 400/400 valid forecasts. Active acquisition does not outperform fixed forecast
queries in this pilot; the full novelty claim remains unproved.

A separate six-station prospective program pilot is running locally. This
publication contains the first verified cycle only, with all 18 outcomes pending.
Future waiting is optional for research progress: the review explicitly compares
historical replay as the main experiment with limited prospective supplementation.
