# 给 ChatGPT Pro / 导师的数据选择复查说明

日期：2026-09-12。请以仓库中实际文件为依据分析，先列会改变数据选择或论文结论的问题，再提出可执行的修改建议。本次重点是数据适用性与研究设计。

## 已完成的结果

项目拟评测 LLM 在专业预报和多模态观测环境下的极端天气证据获取、未来风险判断与决策。目标不要求逐题新增人工 Gold，也不使用 LLM judge 作为主要真值来源；已有机构分析/人工标注数据可以继承，但须明确其上游和定义。

现有候选包括 16 类天气灾害、97 个来源/产品/交付入口。本轮之后，84 项有已解析目标样例、6 项可作目录、4 项尚需许可/账号、3 项尚未取到目标数据。9 项补齐为 TCIR、CAMELSH、CEMS、FloodNet、CrisisMMD、UrbanSARFloods、SenForFlood、GWIS、EFFIS。它们不是 9 个独立信息源；例如 GWIS/EFFIS 共用 ECMWF 后端。

此次共 93 次有界数据请求、975,066,949 字节响应正文，保留失败与部分下载。独立核验检查 1,081 个文件/约 4.73 GB，12 类检查通过。这个数字含解压成员和继承资产，不能与网络流量直接相加作为独立数据量。

此前的历史链试验有 34 个目标、96 个检查点、192 条程序基线记录，其中 32 个在不同参考约定下可结算；包括临时 USGS 数据和存档站报，不等于 32 个最终 QC 真值。它与更早的 ActiveWarning LLM 试验不同。更早两轮 Qwen3-8B 有 1,120 条真实回复，主动取证始终查询官方预报，没有证明增量收益。本轮数据工作没有新增模型调用，不改变这个负结果。

## 优先审查的问题

1. **主研究问题是否足够新且可证伪？** 核心假设是同一最新专业预报和公平预算下，额外证据是否改善固定未来风险/决定；并检验来源重复、表示和时点/流程干预。请结合相关工作指出真正重合点和可区分实验，不能把“数据更多、灾种更多”当作充分 novelty。
2. **哪些来源能形成完整任务？** 每条主任务是否同时具有同目标专业预报、截止前证据、未来参考、质量与版本约定？请推荐首批 2–3 个主任务族，并明确其余来源在感知诊断、事件索引或扩展中的作用。
3. **是否混淆代理量和真值？** 重点检查 FWI/起火概率、AOD/沙尘暴、LST/2m 气温、SWE/新雪/冻雨、流量/水位、SAR 范围/未来洪水预警、社交标签/天气观测。
4. **来源依赖是否会虚增增量收益？** 审查 NHC/HURDAT2/IBTrACS、METAR/IEM/GHCNh、USGS/CAMELSH、MRMS 子产品、S1/S2 与 GEE、CEMS 派生标签、GWIS/EFFIS。
5. **极端正例和独立过程是否不足？** FloodNet 新样例是负例；Urban 正瓦片为开发探查选择；SenForFlood 图例未确定；TCIR 94 ID 未配齐预报。请提出固定分母、多过程、近阈值与普通对照的抽样方案。
6. **自动评分是否可成立？** 需要哪些现成客观标签/QC 政策，哪些只能做继承分析参考？请拒绝以 LLM 判断代替未取得的真值，也不要默认所有原始人工标注都无误。
7. **下一步怎样检验增量而不依赖真实未来等待？** 优先历史多事件回放，区分已证明的原始发布时点与受控时钟；建议合理简单基线、共同专业预报、固定/随机/主动取证对照和消融。
8. **代码与证据有无会改变结论的错误？** 尤其是 Range 续传、标签图例、时空连接、负例、空几何、缺测、质量位、版本身份和源文件绑定。请给出文件位置、影响与验收标准。

希望的输出：先列高影响发现；再给保留/降级/条件扩展的数据选择表；最后给出一套可直接执行的主实验与验收门槛。区分已经有证据支持的事实、你的推断，以及需要进一步下载/实验才能回答的问题。
