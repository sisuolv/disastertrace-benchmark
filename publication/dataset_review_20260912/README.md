# Dataset recovery and research review

Start with [the Chinese review brief](REVIEW_FOR_CHATGPT_PRO_CN.md) and the
[actual dataset report](../../plans/all_dataset_utilization_20260912/README_CN.md).

The latest inventory has 97 source/product/delivery entries: 84 decoded samples,
6 event/derived catalogs, 4 access/licence gaps and 3 missing target samples.
Nine entries improve in this round. All 16 hazard families remain in scope,
with explicit task qualification gaps. This is not a new model evaluation or
proof of positive acquisition value.

This publication adds the previously unpublished candidate audit, advisor
proposal, historical task-chain pilot and expanded recovery bundle. Existing
remote commits and historical experiment results are preserved.

`EXPORT_MANIFEST.json` binds the selected code/reports. `EXCLUDED_ASSETS.json`
records omitted raw assets and environments. The reading ZIP is a convenience
copy of the newly selected files; it does not include the whole Git history.
Use `verify_export.py` to verify a checkout or extracted ZIP containing the
manifest's selected files. Full scientific replay additionally requires the
original local source assets and scientific dependencies.

Private GitHub access is required for the repository. Alternatively, use
`chatgpt_pro_dataset_review_20260912.zip` as a reading attachment.
