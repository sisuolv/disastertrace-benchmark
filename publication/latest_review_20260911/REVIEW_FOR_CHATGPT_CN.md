# 给 ChatGPT 的 DisasterTrace 复查说明

请先读仓库根目录的 [最新进展](../../LATEST_PROGRESS_20260911_CN.md)，再按本文定位代码。
请使用 `sisuolv/disastertrace-benchmark` 的 `next-phase-v1` 分支，并记录读取的 commit。
本说明对应 2026-09-11 的代码/报告快照；更早文件里的“当前阶段”属于历史记录。

## 需要你帮助判断的事项

### 研究贡献

当前目标是评测固定天气产品目标下的证据使用，测量支持/不足证书、预算可达性、版本、
覆盖和引用错误。结合 `plans/v5_0910_feasibility_12h_20260910/reports/NOVELTY_AUDIT_CN.md`，
请判断贡献是否已被近邻 benchmark 或充分性方法覆盖；若只是应用迁移，说明需要什么
最小实验才能形成有意义的新增测量，而不是默认建议增加灾种或模型数量。

### 评分正确性

重点检查 `disastertrace-starter/src/disastertrace/active_forecast/`：

| 文件 | 重点问题 |
| --- | --- |
| `schema.py` | 类型、精确数值、四类支持、时间判定、重复版本、空间分区和来源定位是否合法 |
| `core.py` | yes/no/unknown、最小充分证据集合、剩余成本、引用与预算的边界是否正确 |
| `public.py` | 未读值、质量、私有参考、来源哈希或未来材料是否泄漏到公开字段 |
| `legacy.py` | 冻结资料导入是否保留源语义，是否错误升级历史可用时间 |
| `provenance.py` | 哈希、路径、JSON Pointer、字节和帧内区域选择器是否足够可靠 |
| `replay.py` | 与原型的比较是否真的检验语义，是否遗漏故障或改变历史结果 |

参照 `tests/active_forecast/` 的 59 项测试，特别关注独立可能世界枚举、恒答 unknown、
空证书、未读引用、指定版本、缺测、成本不等和浮点边界。精确证书看到私有完整池，
仅是事后成本界，不是一个可以在线访问 Gold 的取证策略。

### 数据与实验有效性

请区分产品事实和物理结果、归档回放和前瞻可用性、自然缺测和受控删资料、表格图和
原生图像、代码兼容性和模型能力。NHC 有同目标修订；GHCN 日际、USDM 周际及 SEVIR
帧际变化本身不是订正。HURDAT2 只在评估器私有结果层使用。

V5 可行性阶段完成 3,599 次开发模型调用和 28 个单 H100 作业。最新内核阶段没有新增
模型调用。104 个导入样本与 41,600 个程序评分场景均不是新 GPU 成绩。
原生缺测 12 帧的标签不均衡、模型恒答行为、协议重跑和事后探索性辅助都需纳入解释。

请检查分组泄漏、选择偏差、语言骨干谱系、来源许可、公开表示可解性和基线强度。
当前不需要逐题人工复核，也不以 LLM judge 作为参考答案；如某项任务不能自动可靠
准入，应建议明确拒绝或缩小子集。

## 建议交付格式

1. 按 P0/P1/P2 列出具体问题，引用文件和行号，说明触发条件及对结论的影响。
2. 区分已证实问题、合理怀疑和附件缺失导致无法判断的问题；不要将猜测写成已发现缺陷。
3. 检查哪些关键主张已有证据，哪些必须收缩；若没有发现明确代码错误，直接说明。
4. 给出最多五项优先修改，并提出能改变研究结论的最小补充实验。
5. 判断是否适合继续当前方向、缩小为诊断集，或调整主要科学问题。

## 附件与执行边界

私有仓库需要复查工具具备访问权限。仅提供私有 URL 不会自动授予 ChatGPT 访问权限；
也可将同目录的 `chatgpt_review_20260911.zip` 作为阅读附件。
`READING_CONTENTS.json` 在 ZIP 内记录每个文件的哈希和未包含的内容。
附件供研究/代码阅读，不包含完整推理与数据还原依赖。

新内核单元测试可在已有兼容 Python 环境中运行：

```bash
cd disastertrace-starter
PYTHONPATH=src python -m pytest tests/active_forecast
```

原始验证使用 Python 3.10.12、Pydantic 2.13.5，依赖见 `pyproject.toml`。
本次上传会在选定发布文件的独立目录中再次执行这组测试。
来源/GPU 重建脚本需要完整本地资料；缺少依赖时请报告缺失，不要重新启动历史模型
worker、下载权重或调用付费 API 来替代复查。
