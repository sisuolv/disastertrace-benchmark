## 1. 本轮要取得的结果

下一阶段以四项可检查的证据为目标：

1. 一份真实证据变化清点：证明候选领域在预测截止前确实存在与目标相关、可核验的证据变化。

## 3. 推荐科学主线与证伪条件

### 3.1 核心问题

> 面对同一个未来天气风险目标，agent 能否持续维护当前有效的证据，并区分“证据状态需要修复”和“风险概率需要调整”？证据处理错误会对后续行为和预测造成多大影响？

主角色采用 Role D：获取合法资料、维护来源与事实状态、持续提交风险概率；允许使用合格的专业预测或统计后处理作为输入。当前不要求通用 LLM 求解数值天气场，也不把搜索或调用天气模型本身作为主贡献。

### 3.2 主张与必要证据

## 5. 三个必须先补上的实验定义

### 5.1 AgentView 与评分参考分离

当前 `ledger.py` 生成 `kind`、`supersedes`、`information_utility` 等派生字段，`p1_harness.py` 直接向方法传递 ledger entry。它是仪器 scaffold，不能不加区分地作为正式主实验输入。

建立三个逻辑视图，可复用现有 `monitoring_v1/views.py`，不必建立第二套运行框架：

| 视图 | 内容 | 使用者 |
|---|---|---|
| Raw AgentView | 原文、原生 AMD/COR 标记、来源身份和合法时间元数据 | 主实验 agent |
| Tool-assisted AgentView | 登记的可部署解析/规范化工具仅依据当时合法前缀计算的输出 | 明确命名的辅助臂；记录工具来源和成本 |
| ReferenceView | 独立核验标签、评分参考、不能事前取得的结果和后续 adjudication | 评分器与分析；不进入普通 agent 提示 |

原生标记和公开工具输出不因与标签有关就一律隐藏。关键是标明任务测的是 agent 自己识别关系，还是使用给定关系继续判断。人工金标 oracle 单独命名，不伪装成可部署工具。

验收：在固定原始证据下改变评分参考标签，Raw AgentView 与提示指纹必须不变；追加未来证据不得改变过去 AgentView。规范化工具的输出不能通过读取 ReferenceView 得到。

### 5.2 Fresh / Transcript / Structured

现有 APPEND 只有证据历史。不能只把 STATELESS 改为 full-prefix 后仍宣称两者代表不同记忆机制。

| 新臂名 | 共同外部信息 | 额外自写状态 |
|---|---|---|
| FRESH_FULL_PREFIX | 当前完整合法证据前缀及共同工具权限 | 无历史模型输出；每次从合法资料重算 |
| TRANSCRIPT_STATE | 同一前缀及权限 | 历史公开判断、提交、笔记；不要求隐藏思维链 |
| STRUCTURED_STATE | 同一前缀及权限 | 模型自写、注册 schema 的状态摘要 |

评分器在三个臂都保留最后合法生效状态。Fresh 不读自身旧输出，不表示评分器遇到未提交就删除历史预测。输出规范、决策机会和可访问的原始前缀保持一致；额外自写状态是实验处理，token 成本如实记录。

初版只使用所有臂都能容纳完整前缀的切片，不以静默截断制造“同信息”假象。共同输入中的证据顺序、当前包是否重复出现、提示模板和输出预算均登记。

旧 STATELESS 保留为明确命名的 delta-only stress 条件，旧结果和语义不覆盖。长上下文压缩、检索可达但未实际读取等另立实验，不能与本主比较混报。

### 5.3 规范化对照与预测器对照分开

保留 `deterministic resolver + qualified predictor` 作为系统基线；另设同一 LLM 的 Raw vs Tool-assisted 配对，避免同时换模型和输入而把效果全归因于解析。

工具辅助视图保留可追溯的历史资料；“不是当前有效公告”不等于“没有任何历史预测信息”。若工具删除历史或改变上下文长度，记录为处理内容，不能把差异全解释为版本关系修复。

首轮不做全因子网格：先在代表性的开发父状态上做这个配对；如果普通工具足以解决全部问题，收缩主张，不故意禁用工具以维持难度。

## 8. 评分、统计与实验最小集合

### 8.1 第一版正式输出

```text
Q = (1/N) * sum_j sum_k w_jk * (p_eff[j,k] - Y_j)^2
sum_k w_jk = 1

IG = (1/N) * sum_j sum_k w_jk *
     ((b_latest[j,k] - Y_j)^2 - (p_eff[j,k] - Y_j)^2)

Delta_repair = E[Q_original - Q_repaired | eligible parent, registered continuation]

Z_duplicate = |p_duplicate - p_identity_anchor|
              - |p_identity_repeat - p_identity_anchor|
```

Q 是固定评分网格上的平均损失，不自动称连续时间积分；IG 使用同评分时刻最新合格基线。repair 与 duplicate 的总体是登记的合格父状态，不能外推成所有天气目标的自然平均效应。

公式在 Y 完整的注册总体上直接计算。存在未结算 Y 时，分别报告已结算子集的 Q、其目标分母/覆盖率，以及整个注册总体的缺失结果敏感性界；不将缺失当负例，也不把子集均值冒充完整总体分数。模型失败和无提交仍按 fallback 评分，不属于结果 Y 缺失。

事实分数以预定 `(slot, checkpoint)` 的实际状态评价，另外报告未知参考的覆盖。模型不输出事实不能减少分母；参考未知不能强行当错。程序金标只用于评分。

`RV_k = L(p[k-1],Y)-L(p[k],Y)` 可作事后描述；其累计值会消去中间项，不替代 Q。负 RV 不证明事前非理性。严格等价重复引起漂移也不自动证明有害，要另看状态错误或损失。

### 8.3 推断与停止

- 同一目标的 checkpoint 共享一个 Y；嵌套阈值只允许逻辑一致结果。缺失 Y 敏感性界和抽样 CI 分开报告。
- 过程/时空块是主要相关性单位；跨站同一天气系统不能默认独立。过程划分规则预定，并做合理替代分组敏感性。
- 同父模型重复只估计模型随机性；不虚增天气样本数。远程 seed 不保证相同响应，调用次序随机化/分块并记录 provider 时间变化。
- 等价界与实际效果界根据科学/决策意义、预测尺度和基线提出，开发方差用于算所需精度；不看希望得到的显著性倒推界限。
- 第一版采用固定样本范围/硬运行上限。若要持续查看推断并提前停止，另注册符合假设的序贯方法；普通 CI 不能反复看至显著。
- 时效先报告固定截止合规率、未修复率和完整固定观察窗内的受限响应时间；有提前失访时另处理删失，不沿用错误 KM。

## 11. 继续、收缩与暂停规则

| 观察到的结果 | 决定 |
|---|---|
| 评分前没有足够类型/覆盖的相关变化 | 调整观察窗/日历并重查，或进入 QN；不先扩模型规模 |
| 来源关系无法可靠核验 | 限定可评分子集或改任务；未知不变成自动 gold |
| 普通可部署工具解决全部重要问题 | 定位工具贡献，评估是否仍有诊断价值；可收缩为数据/流程资源 |
| Fresh 与状态方法精确等价 | 收缩状态携带优势主张；继续判断其他失效与 benchmark 价值 |
| 修复事实有益但概率损失影响精确接近零 | 主张状态可靠性，不主张有害概率修订 |
| 区间宽、独立过程少 | `INCONCLUSIVE`；先评估增加独立过程的成本与精度收益 |
| 存在跨过程、可重复且修复后改善的失效 | 冻结确认设计，再投入更广模型/过程验证 |
| Living 只有下载或合成模拟 | 保留 C5 为未完成，不宣传真实前瞻评价已运行 |

不要求模型必须出错才保留样本，也不要求新 benchmark 必须让某种方法获胜。扩域不能补偿核心测量或科学问题的缺失。
