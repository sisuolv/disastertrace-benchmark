## 4. 核心发现

### R1 / P1（研究归因）：读取资料与切换校准器一起发生

位置：`calibration.py::predict`、`fit_regional_baselines.py::main`。

当前原始频率值经过两套分别拟合的单调映射：空补证走 `base`；非空补证走 `evidence`。后者即使回退到同一个base/no_taf/pooled频率单元，仍使用evidence映射。

本次合成探针使用同一原始频率单元：未读取时输出0.02；加入一份missing结果后输出0.20。没有修改原始频率单元，变化来自映射选择。这个探针不代表真实银行具有这两个值，更不能据此断言已有收益全部由映射造成。

读取/缺失状态本身可能有预测信息；单独拟合两类校准器也不是数学错误。但是“f(B,E)-f(B)”混合了原始分数变化、观察状态以及后处理变化，不能自动等同于报告内容的价值。

最小后续：对旧轨迹做不改分数的诊断，保存raw score、命中单元、回退级别、read/missing mask、校准器家族、前后概率；再在新的开发冻结里比较内容与mask、共同/分离后处理。不得根据已见测试胜负选用某一校准器。

### R2 / P1（基线稳定性）：PAV的先验强度随不同原始概率的数量增长

位置：`regional_calibration.py::fit_monotone`。

实现明确在每个不同的原始概率上增加一对Laplace伪计数，随后做加权PAV。若有K个原始概率单元，总伪权重为2K；其相对有效校准样本量可能很大。

合成解析例子：100个负结果全部落在同一原始概率单元，输出1/102≈0.009804；100个负结果分到100个彼此很接近但不同的原始概率单元，各单元输出1/3，PAV不会合并相等的比率来消除该伪计数。这是该正则化规则的结果，不是PAV算法计算出错。

真实静态报告中1km的校准分数较raw B变差，值得按单元核查；本次未证明这些真实差异就是先验造成。应输出每区域/阈值的K、真实权重、2K、正例数、外推范围、校准曲线和分块不确定性。新的平滑/收缩方案只在训练和校准数据上选定，旧BANK不覆盖。

### R3 / P2（设计限制）：没有TAF时，补证的具体内容被丢弃

位置：`calibration.py::feature_key`。

candidate为None或projection unavailable时提前返回`[threshold,"no_taf"]`，不会加入E计数。合成探针中，一份明确低能见度和一份明确高能见度的合法产品，在no_taf条件下得到完全相同的频率键及输出。

这是当前冻结预测器的表达能力边界，不是证据理论无效。应报告无TAF/冲突/不可投影占比和此类机会的表现。新后端可采用有合法观测时的明确持续性或带缺测状态的共享预测器；独立拟合后另起版本，不临时手改无TAF概率。
