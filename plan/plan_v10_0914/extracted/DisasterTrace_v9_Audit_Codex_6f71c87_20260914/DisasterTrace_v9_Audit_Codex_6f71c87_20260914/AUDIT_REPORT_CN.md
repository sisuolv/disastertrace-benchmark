## 5. 本轮需要处理的发现

### A1 / P1：补证效应与后校准映射切换尚未分离【实现行为已复现；研究归因风险】

位置：`monitoring_v1/calibration.py::predict()`，`feature_key()`，`regional_calibration.py`；拟合脚本`fit_regional_baselines.py`。

`predict()`以`disclosed`是否非空决定采用`base`或`evidence`后校准表。即使没有TAF、证据分支仍返回同一个`no_taf`频率格，也会切换校准表。本次合成诊断中，频率格和原始概率均不变，输出由0.2变成0.4。

这不是已经证明预测器实现错误：按资料可用状态条件化的校准可能是有意的统计模型。但“预测数值改变”不能全部归给观测内容，真实改善/损害也不能未经控制就归因于模型选到了更有用的资料。

最小后续：保存`selected_cell_key / fallback_level / raw_probability / calibration_family / calibration_hash / acquisition_mask / evidence_values_hash`；对既有真实轨迹扫描实际命中数量，再做固定频率提取与固定校准的交叉诊断。不要立即统一两表或改旧银行。

产物：`CALIBRATION_ATTRIBUTION.json`与按地区、阈值、缺测、格子支持度的分层。合成诊断见`audit_probes/CALIBRATION_FAMILY_DIAGNOSTIC.json`。

### A2 / P1：当前E02高分和F成绩不是同一条E→F管线的结果【源码与实验合同支持】

E02通过`evidence_diagnostic.py`生成直接/逐槽回答；当前连续F使用`adaptive.py`中的常规`model_messages(bundle,head)`。没有证据表明E02逐槽结果经过程序汇总后已经进入这批连续F。

不能把“Flash E=126/126”和“Flash F与FOLLOW同分”拼成一个已控制的中介效应实验。它们提供开发线索，但资料、样本、输出合同和运行状态不同。

最小后续：保留原生模型输出；增加明确命名的“模型逐槽输出→确定性汇总→冻结预测器”管线，与原始汇总和纯程序参照在同一合法输入上比较，再进入真实会话。汇总器不能读未获取资料、未来结果或隐藏充分性见证。

### A3 / P1：H15本轮COPY对照不能识别多次修订的状态效应【设计范围】

`run_api_pilot.py`只选`lead_hours == 1`并固定`base_bound_override`。这批是合理的同批COPY基线，但不足以检验同一物理目标在多个截止之间的持续覆盖、旧值沿用、取消或后续新基线更新。

最小后续：针对同一个目标合同登记至少两个合法cutoff，或恢复经过匹配的1/3/6h机会。固定结果只登记一次；分别运行两种协议和FOLLOW/COPY_CURRENT/COPY_BASELINE/冻结融合程序。不能只是增加更多不同目标然后声称重复修订已验证。

### A4 / P1：区域校准已经实现，但极端支持仍不足【数据限制】

覆盖表中Bay的1km校准零正例；Denver的1km、5km校准均零正例，Denver拟合期分别只有1与8个正例。PAV加平滑能输出概率，不代表尾部区分度或可靠性获得验证。

最小后续：保留当前银行作为冻结基线；在新的开发期评估raw、收缩/正则化融合和校准的选择，按过程划分，不利用Denver已选正例反复调参再汇报同一天收益。展示常数/持续性、校准支持、缺失敏感性及过程不确定性。

### A5 / P2：普通日历与已知正例诊断必须持续分表【目前披露正确】

普通子集1km为0个正例机会；5km为47个。Denver Jan9诊断有3个1km正例、11个5km正例，但选择使用了已知结果。后者可以帮助研究机制，不能作为自然发生率、无偏总体收益或独立确认。

目前最终报告已经明确披露这一点，不是发现隐瞒。新结果继续保留该标签；不因Denver更好就换主数据集。

### A6 / P2：API计算和费用语义不等于真实计算占用【目前部分已披露】

`api_capture.py`保存客户端HTTP时间，`provider_compute_seconds=null`。调用工作进程把这类时间传入通用成本/时序路径。应继续区分客户端延迟、服务端未知计算、模型token、研究情景程序1ms与实际基础设施费用；不能比较不相同测量口径后声称部署加速。

E01的62个未知/待定属于已保留事故证据。存在原始响应不等于账本已经结算，也不能默认没费用。新对账只能引用原请求与原响应/usage；证据不足保持未知。

### A7 / P2：发布包不支持本次完整独立重建【交付限制】

复查入口明确省略部分大原始资料、完整F事件日志和检查点。这是如实披露，不是实验失败；但接下来最好交付一个小而完整、无需历史大目录的复现胶囊，使外部审阅能真正跑通一例。

## 7. 研究结果怎样解释

自然子集5km中：FOLLOW约0.064305；batch_program约0.069353；Flash selector+program约0.068081；Pro selector+program约0.066889，较低更好。单个地区/日期可能改好，不能只报获胜行。Denver探索诊断中程序及selector+program有小幅改善，但不构成总体预测收益。

最终摘要的新概率计数采用与可见当前值/基线值都相距>0.005，不能说“0次新概率”等于全部逐位相同。分析应同时保留精确相等、1e-6、0.005三档，并分别查看proposal、admitted、effective。统一报告`loss_delta=method-follow`与`gain=follow-method`，避免不同版本正负号混用。

温度192轨迹是重要进展，应直接复用；它评价版本流与程序，不是温度LLM、主动取证或真实热浪处置。当前固定阈值三日事件也不能自动等同所有地区的热浪/寒潮标准。
