# DisasterTrace Codex 执行包

建议给 Codex 同时提供 `START_HERE_CODEX_CN.md` 和 `CODEX_MASTER_PLAN_CN.md`；任务状态与依赖使用 `CODEX_BACKLOG.json`。

- 总计划：研究取舍、现有接口、完整状态分支、研究准备状态机、数据门槛、强基线及统计。
- 启动提示：限定第一轮 C00—C05，不自动执行全部研究路线。
- 工作包：20项，C18/C19为条件扩展，每项含依赖、产物、测试、权限和退出条件。
- 合成准备fixture：只供后续实现单元测试的说明性数据，不是实际天气或可直接部署配置。
- 来源索引：两份用户材料哈希、当前提交、实际读取代码与官方资料范围。
- `validate_plan.py`：只检查本包的JSON、任务依赖、默认权限和说明性逻辑；不导入或测试用户仓库。

本包生成过程没有修改GitHub、启动模型/GPU或下载科学数据。旧运行的250项测试、720次模型调用属于仓库报告，不是本包执行结果。

检验本计划包：`python validate_plan.py`。这不是后续代码实现或科学准入的替代品。
